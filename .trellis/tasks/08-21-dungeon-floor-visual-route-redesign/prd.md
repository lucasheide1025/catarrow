# 地下城三層視覺動畫與第三層路線重製

## Goal

全面重製地下城第一層、第二層與第三層的進入展示，使每一層都有清楚的探索節奏與族群氛圍；同時重做第三層目前意義薄弱的固定三選一路線，讓玩家能根據可見風險、資源與戰利品做真正影響後續戰鬥的決策。

## Requirements

- 第一、二、三層需有不同的畫面構圖、資訊層級、轉場與入場動畫，不再只用固定漸層、表情符號與倒數按鈕。
- 三層入場敘事固定為：
  - 第一層「踏入領域」：大門開啟、族群環境分層顯現，最後展開探索地圖。
  - 第二層「危機升高」：鏡頭下沉、警示與敵影掠過，顯示本層強化規則後進入戰場。
  - 第三層「命運分岔」：Boss 剪影先登場，路線印記環繞地圖，再揭露第一組二選一。
- 每層首次抵達要完整播放入場演出；同次遠征重新整理或斷線重連只播放約 0.8 秒短轉場，不重播完整動畫。已看過狀態需隨遠征保存並同步給組隊成員。
- 幽靈、山岳、昆蟲、職場、考試、廟宇、寶藏七族沿用同一套可維護的動畫骨架，但要有可辨識的族群色彩、粒子、前景剪影、轉場與音效差異。
- 美術採七張族群專屬全景主圖，每族一張；前端以遮罩／景深拆成前、中、後景，依樓層改變光線、霧效、敵影、粒子與鏡頭運動，在不載入 21 張大圖的前提下呈現三層差異。
- 現有族群戰鬥背景只作圖片載入失敗或低階裝置降級時的備援，不再作為新版樓層入口主畫面。
- 單人與組隊共用相同的樓層視覺及路線規則；組隊只能由房主做權威選擇，其他隊員同步看到同一族群、樓層、路線與演出階段。
- 第三層不可再只是進場時選 A/B/C，之後走內容近似的固定直線；每次選擇都必須清楚揭露至少一項風險／代價與一項收益，且實際影響房間組成、隊伍資源、Boss 條件或最終獎勵。
- 第三層採「三段式動態路線」：每一段提供兩個明示風險與收益的選項；選擇會累積路線印記，三次決策的印記組合會改變後續房間、Boss 開場效果與最終戰利品，不在進場時一次鎖死整條路線。
- 路線印記分為四個共通玩法原型，各族只替換名稱與視覺包裝：
  - 狩獵：提高敵方威脅與戰鬥密度，換取更多素材／卡片掉落。
  - 補給：提供治療或增益，但降低最終寶箱收益。
  - 詛咒：立即承受負面效果，換取最高稀有獎勵或 Boss 弱點。
  - 探索：增加事件與未知房，結果波動較高並可能取得特殊收藏品。
- 新路線必須以穩定 seed 與快照保存，重新整理、斷線重連及組隊換頁都不得重抽或產生不同結果。
- 現有進行中的 `branchFloor`／`branchChoice`／`branchStep` 舊遠征必須能照原規則完成；新規則只套用在新建立的遠征。
- 手機 360×640 與 390×844 必須能看懂當前樓層與核心選擇，不得產生巢狀垂直捲動或讓主要操作被動畫遮住。
- 動畫可豐富但不可拖慢重複遊玩；提供 `prefers-reduced-motion` 降低動態版本，且動畫失敗不得阻塞遊戲流程。
- 現有複數怪戰鬥的演出、加成按鈕與提前結算規則，需在地下城單人與組隊保持一致。

## Acceptance Criteria

- [ ] 第一、二、三層各有完整且彼此不同的入場 storyboard、資訊內容與操作節點。
- [ ] 每層首次抵達播放完整演出，同次遠征重連只播放短轉場；不得因重播動畫延遲恢復操作。
- [ ] 七個族群不靠讀文字也能從主色、環境特效或剪影辨認，寶藏族有明確 fallback／專屬視覺。
- [ ] 七張全景圖具備手機安全構圖區，分層動畫不遮擋樓層資訊與主要操作；主圖失敗時可無阻塞切換既有背景。
- [ ] 單人及所有組隊成員看到同一族群、樓層、路線結果與動畫進度；非房主無法改寫路線。
- [ ] 第三層每一個可選項都明示風險與收益，選擇會可驗證地改變後續房間、資源、Boss 開場條件或戰利品。
- [ ] 第三層包含三個決策節點，每個節點為二選一；已取得的路線印記與目前造成的影響可隨時查看。
- [ ] 每次二選一從四種路線原型中提供兩種不同選項；顯示共通規則及族群化名稱，不讓玩家只靠猜測判斷後果。
- [ ] 第三層結果由穩定 seed 產生並持久化，重連不重抽、不重複套用效果或領取獎勵。
- [ ] 舊版進行中遠征可正常完成，新版遠征使用版本化 schema。
- [ ] 360×640、390×844、桌面版完成視覺與操作驗證；無主要按鈕溢出或必要內容不可達。
- [ ] reduced-motion、音效播放失敗及中途重連皆不會卡死流程。
- [ ] 地下城單人與組隊的複數怪 UI／演出行為與自由狩獵版本一致。
