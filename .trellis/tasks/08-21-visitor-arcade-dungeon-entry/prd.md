# 新版訪客地下城探索與預約入口

## Goal

讓預約系統中的訪客從新版簡化訪客入口進入「貓小隊冒險」，並直接使用新版既有的地下城探索體驗，不再導向舊版訪客學籍系統。

## Requirements

- 預約會員中心的遊戲入口必須導向新版訪客模式 `/?arcade`。
- 入口文案必須改成訪客冒險語意，不再顯示「訪客學籍系統」或暗示會進入舊學籍流程。
- 進入新版訪客模式時，不再建立舊 `guest_prefill` 資料，也不把預約會員姓名、信箱、電話或學籍識別帶入 Arcade。
- 新版訪客模式維持簡化流程：暱稱、同行貓、本機進度、選擇冒險；不得重新接回 `GuestApp`、會員學籍或舊 `DungeonLobby`。
- 地下城探索沿用 Arcade 現有三種冒險與既有單人／組隊流程，不複製舊地下城的挖掘、學籍、裝備或帳號依賴。
- 本次不得改壞舊版 `?guest=1` 的既有直連能力；只把預約系統顯示的入口移到新版。

## Acceptance Criteria

- [x] 預約會員中心按鈕顯示「🎮 進入訪客冒險」。
- [x] 點擊該按鈕會進入 `/?arcade`，不會進入 `/?guest=1`。
- [x] 點擊入口不會新增或更新 `sessionStorage.guest_prefill`。
- [x] 新訪客可完成「輸入暱稱 → 選同行貓 → 開始冒險 → 選擇地下城」流程。
- [x] 已有本機 Arcade 進度的訪客會直接看到新版冒險大廳與既有地下城選項。
- [x] `?guest=1` 舊入口仍可由其他既有連結獨立使用。
- [x] 相關測試與 production build 通過。

## Out of Scope

- 重做 Arcade 已存在的戰鬥、三種地下城、組隊房間或競技場。
- 把預約會員身分同步成 Arcade 帳號或雲端進度。
- 移除舊版 `GuestApp` 或全面遷移所有舊訪客連結。
