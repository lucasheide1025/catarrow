# 組隊地下城事件與寶箱修復

## 目標

讓組隊地下城的一般事件、特殊事件與寶箱房具有一致、可理解且不會提前跳回地圖的多人流程；畫面說明、實際效果與最終掉落必須相符。

## 已確認問題

- 房主在自己的事件流程完成後會直接推進，沒有等待其他有效隊員。
- 一般與特殊事件在組隊模式只顯示效果，沒有可靠地把效果套用到共享隊伍狀態。
- 特殊事件的選項沒有保存為共享結算結果，隊員之間可能看不到相同結果。
- 普通寶箱由每個客戶端自行隨機，組隊成員可能得到或看到不同結果。
- 普通寶箱素材硬性封頂 T4，且金幣、素材數量與道具池沒有完整反映地下城種族與難度。

## 功能需求

1. 一般事件、特殊事件與寶箱房皆採用「共享結果 → 個人閱讀／領取 → 全員完成 → 房主推進」流程。
2. 房主完成自己的操作不得直接返回地圖。
3. 所有仍在隊伍且存活的成員都完成後，才可自動推進；離隊或已陣亡成員不阻塞。
4. 房主保留明確的異常處理入口，但一般操作不得繞過全員等待。
5. 一般事件效果由房主只結算一次，並套用到正確的隊員、怪物或後續戰鬥狀態。
6. 特殊事件由房主作出隊伍選擇，選項、代價、隨機結果與效果只擲定一次，所有隊員看到同一結果。
7. 畫面上的效果說明必須由實際效果資料產生；無效果才可顯示「沒有發生變化」。
8. 寶箱房獎勵由房主只生成一次並同步，所有隊員看到同一組可領取內容。
9. 寶箱素材族系必須符合地下城族系；素材階級與數量、金幣、道具稀有度必須隨地下城難度提升。
10. 寶箱領取需避免重複發放，並保存每位隊員的完成狀態。
11. 寶箱房三張牌不得固定綁定「第一張金幣、第二張藥水、第三張素材」；每張牌都必須由符合族系與難度的混合獎勵池抽出並打亂位置。
12. 混合獎勵池至少包含金幣、對應族系素材、藥水、一般道具與稀有獎勵；三張候選應提供實質差異，避免三張完全相同。
13. 第三層路線固定為七間：
    - 第 1～3 間：從寶箱房、陷阱房、事件房、精英房四類中隨機安排三間。
    - 第 4 間：休息區。
    - 第 5 間：商人區。
    - 第 6 間：王房。
    - 第 7 間：地下城獎勵房。
14. 第三層地圖顯示位置、目前位置、進入按鈕文字與實際觸發房型必須使用同一份順序，不得出現房間疊位。

## 驗收條件

- [ ] 兩名以上玩家進入一般事件，房主先完成時仍停留在事件畫面；最後一名有效隊員完成後才回地圖。
- [ ] 特殊事件骰定或選擇後不會立即跳回地圖，所有成員能完整看到同一結果。
- [ ] 顯示 ATK +10% 的事件完成後，隊伍共享資料中的 ATK 倍率確實增加 10%，下一場戰鬥也會沿用。
- [ ] HP、DEF、傷害、怪物 HP／ATK、金幣、物品與隨機事件的顯示結果均與實際套用一致。
- [ ] 寶箱房在不同族系地下城只會抽到對應族系素材。
- [ ] 高難度地下城的寶箱階級、數量或價值明確高於低難度，T5／T6 不再固定只給 T4 素材。
- [ ] 同一個組隊寶箱房不因重新渲染、重新連線或不同客戶端而重新抽獎。
- [ ] 連續建立不同寶箱房時，金幣、藥水、素材與道具不會固定出現在同一牌位。
- [ ] 每個寶箱房的三張候選來自同一套難度／族系加權池，且不會三張完全相同。
- [ ] 同一玩家不能重複領取，同一隊伍不會因房主重複操作而重複套用事件效果。
- [ ] 第三層每條支線都恰好為三間隨機功能房、休息、商人、王房、獎勵房。
- [ ] 第五間商人房與第六間王房使用不同座標；站在王房時只會觸發王戰，不會先開商店。
- [ ] 單人與組隊第三層使用相同的房間序列與地圖座標規則。
- [ ] 單人地下城既有事件與寶箱流程不退化。
