# 鬼怪族 T1 GPT 立繪重製

## Goal

依已核准的 Tier × Encounter 雙軸與半 Q 戰鬥規格，從鬼怪族 T1 延伸完成 T2～T6 全套卡片場景圖與對應戰鬥立繪，建立可供其他種族重製沿用的完整六階視覺基準。

## Confirmed Facts

- 正式圖片生成改用 GPT；本機 ComfyUI 不再負責主要角色創作。
- 鬼怪族 T6 已核准並整合，代表終局神話階級的品質與華麗度上限。
- T1 不得降低臉、毛髮、線條或上色品質；只降低服裝層次、材質稀有度、神器規模、晶體數量、特效強度與身份氣場。
- T1 人形採成熟日系 RPG 角色比例，約 6～7 頭身，不使用 Q 版、真人照片感或過度寫實時裝比例。
- 每 Tier 固定 3 位普通角色與 3 位領袖；T1 槽位為：
  - `ghost_t1_normal_a`／男／暮燈旅者
  - `ghost_1`／女／鏡幕幽姬
  - `ghost_t1_normal_b`／純怪物／星霧絨獸
  - `ghost_t1_mini_a`／男／蒼焰巡獵者
  - `ghost_t1_mini_b`／女／霧紗影舞者
  - `ghost_t1_boss`／純怪物／星環冥鹿
- T1 領袖輪動為 `miniA=男`、`miniB=女`、`boss=純怪物`。
- 角色概念、技能顯示名、掉落物與場景方向已在既有美術聖經批准，不重新發明六位角色。
- 現有網站仍保留穩定 monster/card ID；圖片重製不得修改玩家收藏與 gameplay。

## Requirements

- 使用 built-in GPT 圖像生成，不使用本機 ComfyUI 生成正式角色。
- 每位角色先建立 3:4 卡片場景圖；圖片只含角色與場景，不含卡框、名稱、星級、技能、數值、文字或 UI。
- 卡片圖核准後，再以該卡片圖作身份參考生成同角色戰鬥版。
- 戰鬥版使用純色 chroma-key 背景，後續本機去背為透明 WebP；必須保持臉、髮型、物種、服裝主結構、代表物與配色一致。
- 人形戰鬥版採明確半 Q 化約 3.5～4 頭身：頭臉約占全高 25%，軀幹緊湊、四肢較短且手腳略放大；不得只是把寫實卡圖縮小。獸型可放大頭部與代表特徵約 20～25%，但不得改變物種身份。
- T1 整體感受是「剛踏入冒險的初階幽靈」：仍精緻好看，但裝備簡單、能力微弱、魂火與靈霧尚未穩定。
- 視覺規格必須分成兩條獨立軸：
  - `Tier T1～T6` 控制服裝／材質／神器／文明技術與魔力成熟度。
  - `Encounter 普通／小王／大王` 控制體型、輪廓、構圖占比、姿勢壓迫感與招牌能力辨識。
- 同 Tier 內，小王與大王不得只靠更換道具或少量特效區分；縮到約 200px 時仍必須一眼辨識遭遇階級。
- T1 王可以使用普通材質與低階魔力，但仍必須具備明顯高於 T1 普通怪的體型／輪廓／姿勢與視覺支配力。
- 跨階比較採二維判讀：T1 大王可以比 T2 普通怪更巨大、更具威脅與關卡終點感；T2 普通怪則在裝備、材質與魔力控制上更成熟，但保持普通怪的標準構圖。
- 六個 Tier 必須保留清楚的視覺成長空間；不得把單張圖的完成度誤當成角色設定密度，導致 T1 已使用高階場景、服裝、神器或特效預算。
- T1～T6 不是同一批角色的成長／進化／升級路線。每個 `family × tier × slot` 都是獨立怪物身份，不需要跨 Tier 保持臉、物種、服裝、道具或角色概念的延續。
- 同族跨 Tier 只共享家族級美術語言、色彩範圍、幽靈表現方式與世界觀；不得再以 T6 角色作為 T1 角色的 identity reference，也不得把 T1 描述成 T6 的降配版。
- 女性角色以漂亮為首要造型原則：臉部需清楚、精緻且具有吸引力；幽靈感、危險感與階級差異應由材質、光影、姿態、能力及環境反應建立，不以無臉面具、骷髏化或臉部醜化取代。
- 每次生成先留在 staging／Codex 生成資料夾供人工核准；未核准不得覆寫 `public/` 正式素材。
- 第一輪先生成三位普通角色的卡片圖：暮燈旅者、鏡幕幽姬、星霧絨獸；集中核准男／女／純怪物三種 T1 樣板後才繼續領袖。
- 使用者核准完整 12 張圖後，才統一轉 WebP、整合網站、跑圖片檢查／卡片測試／production build。

## Acceptance Criteria

- [ ] 六位角色的卡片圖皆符合既有角色概念與 T1 華麗度。
- [ ] 同一 Tier 的三隻普通怪、兩隻小王與一隻大王，在卡片縮圖與 200px 戰鬥立繪下都有清楚的 encounter hierarchy。
- [ ] 六位角色的戰鬥圖與各自卡片圖身份一致，且在約 200px 顯示高度仍清楚可辨。
- [ ] 人形比例成熟好看、手部與代表物合理；獸型輪廓完整且不恐怖血腥。
- [ ] 卡片圖為 3:4 場景插畫，無卡框、文字或 UI。
- [ ] 戰鬥圖成功去背，透明角落、無明顯色鍵殘邊、無裁切肢體或特效。
- [ ] 12 張圖均經使用者逐階段核准後才覆寫對應 T1 正式路徑。
- [ ] 整合後未取得卡可看見灰階真實構圖，已取得卡正常顯示彩色圖。
- [ ] 不修改 stable IDs、收藏資料或 gameplay；focused tests 與 production build 通過。

## Rejected Direction

- 已生成的 T1 領袖卡圖與六張戰鬥候選不得整合：它們雖符合 T1 樸素度，但普通／小王／大王的體型、輪廓與壓迫感差異不足。
- 已整合的 T6 圖組也需重新審視 encounter hierarchy；不得再把「整體更華麗」當成王怪辨識度。
- 拒絕把 T1～T6 當成同角色或同原型的視覺進化鏈；已產生的跨 Tier 身份映射不再具有規格效力。
- 第一版 T1 戰鬥圖雖維持角色身份，但比例仍接近寫實成人立繪，屬於「卡圖縮小」而非遊戲半 Q 單位，不得整合。

## Open Questions

- T1～T6 每階可使用的服裝層次、材質、代表物、魔力效果與場景規模預算。

## Calibration Experiment

- 在重做任何正式 monster slot 前，先生成一組不進產品的鬼怪族 `3 Tier × 3 Encounter` 校準圖。
- Tier 採 T1／T3／T6，Encounter 採普通／小王／大王，共九張獨立怪物卡圖。
- 九隻是彼此獨立的測試怪物，不是角色進化，不使用正式 monster ID，也不限制男／女／純怪物輪動。
- 校準中的女性角色同樣必須驗證「漂亮」與 encounter hierarchy 可以並存；漂亮不等於普通怪構圖，王級也不需要靠醜化取得壓迫感。
- 校準圖只驗證兩件事：
  - 橫向能否一眼看出普通怪／小王／大王的體型、輪廓、構圖與威脅差異。
  - 縱向能否一眼看出 T1／T3／T6 的材質、能力成熟度、場景規模與力量級別差異。
- 校準通過後，才把規則套回正式 T1 與 T6 六角色；未通過時不得繼續量產。

## Out of Scope

- 其他族系。
- 改動技能效果、數值、掉落邏輯、收藏 ID。
- 在圖片核准前覆寫正式素材或部署。
