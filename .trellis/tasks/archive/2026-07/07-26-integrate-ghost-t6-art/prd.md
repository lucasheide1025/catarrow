# 整合鬼怪族 T6 核准立繪

## Goal

把已由使用者核准的鬼怪族 T6 GPT 圖組接入本機網站，讓使用者能以實際卡片 UI 檢查構圖、美感與可讀性。

## Confirmed Facts

- 核准圖組共 6 個角色；每個角色各有卡片場景圖與綠幕戰鬥圖。
- 正式 T6 槽位為 `normalA`、`normalExisting`、`normalB`、`miniA`、`miniB`、`boss`。
- `normalExisting` 的穩定怪物 ID 與卡圖 key 是 `ghost_6`；其餘五個 key 為 `ghost_t6_<role>`。
- 領袖映射必須依核准紀錄重新排列：
  - 原獸型 boss 概念 → T6 `miniA`
  - 原男性 mini-a 概念 → T6 `miniB`
  - 原女性 mini-b 概念 → T6 `boss`
- 卡片圖片本身只含角色與場景；卡框、名稱、星級、技能和數值由現有 React UI 呈現。
- 未取得卡片也顯示實際卡圖的灰階暗化版本，保留未知名稱與鎖定資訊，不再以無法辨識角色的通用 SVG 取代。
- 本次只做本機整合與驗證，不部署。
- 工作區已有與本任務無關的使用者修改，必須保留且不得納入本任務。

## Requirements

- 使用核准來源圖，不混入 `.staging/image-generation/gpt-ghost-t6/` 錯誤分支。
- 依穩定 ID／art key 覆蓋鬼怪族 T6 對應正式圖片，不修改收藏資料 ID 或 gameplay。
- 保持卡片 3:4 呈現，圖片不得加入第二層卡框或文字。
- 未取得卡片允許以 lazy loading 載入有限圖片 fallback 鏈，並由 UI 套用灰階、暗化與鎖定狀態。
- 同時將六張核准綠幕戰鬥圖去背，接入對應鬼怪族 T6 戰鬥立繪路徑。
- 戰鬥圖必須保留透明背景、完整角色輪廓與半透明特效，不可殘留明顯綠邊。
- 輸出適合網頁載入的 WebP，避免直接發布 2–3 MB PNG。
- 保留可回滾性：變更範圍限於本次 T6 正式圖片與必要的驗證紀錄／測試。

## Acceptance Criteria

- [ ] 鬼怪族 T6 六張卡在卡片收藏頁皆顯示正確核准角色。
- [ ] 六個角色與 T6 槽位的映射符合核准紀錄，尤其三個領袖槽位不受歷史 `t1` 檔名誤導。
- [ ] 卡片 UI 的名稱、框面、星級、技能與數值仍由現有介面正常顯示。
- [ ] 未擁有鬼怪族 T6 卡時，收藏頁仍能辨識六張卡的灰階構圖，但不揭露卡名、星級、技能或數值。
- [ ] 鬼怪族 T6 六張戰鬥立繪皆在透明背景下顯示，無整片綠幕或明顯綠邊。
- [ ] 正式輸出為 WebP，尺寸與檔案大小適合手機網頁。
- [ ] 相關卡片 catalog 測試與專案 build 通過。
- [ ] 不部署、不修改 gameplay、不碰無關的既有 dirty files。

## Out of Scope

- 生成新圖片或修改已核准角色設計。
- 整合鬼怪族 T1–T5 或其他族系。
- 重命名角色、技能、材料或調整數值。
- 正式部署。
