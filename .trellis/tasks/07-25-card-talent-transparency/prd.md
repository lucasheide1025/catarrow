# 卡片天賦透明化：裝備總效果面板

## 背景 / 問題

怪物卡片的「天賦」系統，玩家反映**裝上去的效果跟顯示對不上、根本不知道怎麼搭**。查 code 後確認落差來自三個隱形機制（`src/lib/cardTalents.js`）：

1. **隱形上限**：`TALENT_CAPS`（傷害 8%、穿甲 10%、爆擊 8%…）。玩家裝 5 張各「傷害+2%」以為 +10%，實際被砍到 +8%，畫面不提示。
2. **名字不同卻共用同一數值池 + 同一上限**：「蓄勁/淬毒/蠻力」全進 `damagePct`（共用 cap 8）；「連擊/挑戰者」全進 `critRatePct`。玩家看到不同圖示，不知道它們暗中合併又互相排擠。
3. **顯示只給「單卡」，戰鬥吃「彙總後砍上限」**：UI 只顯示每張卡自己的天賦與族系套裝，**從來沒有一個地方顯示「這套裝備實際生效的總效果」**（戰鬥端吃的是 `calcCardCombatEffectsFromCollection`）。

## 範圍：第一段（純顯示、零平衡）

**本任務只做「把真相攤開來」，不改任何機制/數值/上限/公式。** 拆分 key、改上限、套裝 vs 天賦流派重設計＝第二段，不在此任務。

## Requirements

1. **裝備總效果面板**（裝備頁 `CardCollectionModern` header）
   - 直接顯示 `calcCardCombatEffects` 的**實際生效值**：每個生效效果一條進度條（`圖示 名稱 ▓▓▓░ 實際值/上限`）。
   - 撞上限的效果明確標示「已滿 ⚠️」並變灰。
   - 每條 bar 下方**自動顯示貢獻來源**（如「含 蠻力×2、蓄勁×1」），預設顯示、不需點擊。
   - 共用數值池的效果，用**友善分類名**顯示（如「傷害系」「爆擊率」），讓「誰跟誰共池」一目了然。
   - 沿用並整合現有的族系套裝狀態顯示。
   - **主動搭配建議**：面板固定一行動態建議，隨當前裝備變化（撞頂→建議換其他天賦；差一張套裝→建議補；有空間→建議可堆），不是只有浪費才出現。
   - 面板可收合，預設展開。

2. **卡面直接顯示天賦**：卡片格（`CardCollectionPrototype`）上直接印出該卡天賦（圖示＋名稱／值），玩家瀏覽收藏即可看到，**不需點進詳情**。

3. **詳情頁補共池說明**：`CardDetailSheet` 的天賦文字補一句「（歸【傷害系】，與同類共享上限 8）」，看單卡時就知道會跟誰擠。

## 限制 / 非目標

- **零平衡改動**：不得修改 `cardTalents.js` 的任何數值、`TALENT_CAPS`、`FAMILY_SET_BONUSES` 值、`getCardTalent`/`calcCardCombatEffects` 的計算邏輯。只能「讀取其輸出來顯示」＋新增純顯示用的 metadata。
- 不做「點 bar 高亮貢獻卡片」的互動（留第二版）。
- 不改任何戰鬥端計算。

## Acceptance Criteria

- [ ] 裝備頁能看到「裝備總效果」面板，其數值與 `calcCardCombatEffectsFromCollection` 的實際輸出一致（顯示＝實際生效）。
- [ ] 撞上限的效果有「已滿」視覺標示；每條效果顯示貢獻來源。
- [ ] 共池效果以分類名顯示，玩家能看出蓄勁/淬毒/蠻力算同一類。
- [ ] 面板底部有隨裝備變化的主動搭配建議（至少涵蓋：撞頂、差一張套裝、有空間 三種情境）。
- [ ] 每張卡在收藏格上直接看得到天賦，不需點進詳情。
- [ ] `CardDetailSheet` 顯示共池/上限說明。
- [ ] `cardTalents.js` 的數值/caps/公式完全未改（git diff 佐證）。
- [ ] 教練切「射手模式」進裝備頁不白屏（見 [[feedback_admin_mode]]）。
- [ ] 訪客/空收藏/未載入時面板不崩（graceful）。
- [ ] `CI=true npx react-scripts build` 通過。
