# 冒險者公會重生：委託遠征＋階級重做＋公會專屬裝備

## 背景 / 問題

現有冒險者公會「雞肋」：功能多但**沒有冒險者的味道**。病因：
1. 委託是「順便達標的被動計數」（討伐 X 隻某怪，玩家本來就在打），沒有主動出任務的感覺。
2. 獎勵（金幣/箭露/寶箱）跟其他系統重疊，無獨特性。
3. 階級（青銅→神話）只加乘「公會任務金幣」，自我餵養、無真實身分感。
4. 缺少大廳/NPC/故事包裝，是「清單」不是「地方」。

## 願景

玩家是一名冒險者：走進**公會大廳** → 公會長貓給一張**故事委託單**（隨機怪物陣容、危險星等）→ **出發連打數場討伐遠征** → **凱旋回報**領賞 + 聲望 → 階級爬升解鎖更危險更肥的委託 → 用公會賺的**專屬裝備**在遠征裡變更強。

## 架構定位：獨立遊戲（比照 `src/zombie/`）

冒險者公會做成**自成一體的獨立遊戲模組**（DDD 分層，如 `src/guild/`），與主線 RPG 解耦。**只從主線帶入兩樣輸入**：

1. **射手等級**（`archerLevel.js` 的等級/加成——代表玩家真實射箭累積的實力，會被帶進公會）。
2. **貓貓陪練**（貓咪陪你出任務，帶入貓的戰力/技能）。

**明確不帶入**：怪物卡片（虛擬裝備）、主線 RPG 裝備、檢定/圖鑑加成、`calcArcherStats`。公會戰力改由**公會專屬裝備**提供。

→ 於是公會戰力 = f(射手等級 + 貓貓 + 公會裝)，**架構上天生與主線隔離**（不是靠避讓，是根本分開的遊戲）。

## Requirements（四大支柱）

### 1. 委託 = 隨機指定怪的「多場討伐遠征」（核心玩法）
- 接委託 → 系統**隨機 roll** 一組怪物（依委託客戶/族系 + 危險星等），**連續打數場**才算完成。
- 場數：一般 3 場 / 危險 4 場 / 極危 5 場（提案值）。
- HP 跨場延續、中途可短休/用道具；中途陣亡＝**委託失敗**（當天不可重接同一張，提案）。
- **重用現有戰鬥引擎**（每場走 MonsterBattle 單怪戰鬥），不另寫戰鬥迴圈。
- **補給/生存層（重用殭屍末日 survival）**：出發前要備**飲食/水/補給品**，遠征途中消耗；不足會影響狀態（如無法回復、減益、甚至被迫撤退）。重用 `src/zombie/` 的 backpack/survival 機制（`domain/backpackEngine`、`data/itemData` 等），讓委託變成「要準備補給的長征」而非純戰鬥。
- 完成 → 凱旋回報 → 獎勵（聲望 + 公會幣 + 公會裝掉落 + 戰利品機率）。

### 2. 階級系統「整個重做」
- **廢除**舊 `adventurerSystem` 的 RANKS/XP/mult 邏輯與「公會金幣加乘」。
- 新階級靠**完成委託遠征累積聲望**升階（進度綁在新玩法，不再爬不動）。
- 階級解鎖：**更高危險委託**、**公會商店層級**、**稱號 + 冒險者證(可分享) + 獨占外觀**。
- 階級**只給身分與解鎖，不給戰力**（保護主線平衡）。

### 3. 公會專屬裝備系統（獨立戰力，只影響公會遠征）
- 一套**公會限定裝備**（槽位提案：主武/防具/飾品/斗篷），從委託獎勵 + 公會商店取得、可強化。
- **鐵律：公會裝的數據只在「公會遠征戰鬥」的戰力計算中生效，永不餵入** `calcArcherStats`/`calcEquippedBonus`/主線任何戰鬥（打怪/地下城/組隊/世界王/決鬥）。
- 獨立儲存、獨立計算函式。

### 4. 大廳 + NPC + 故事 + 美術
- 公會畫面改成**大廳場景**（委託板/火把/氛圍底圖）。
- **公會長貓 NPC**：依階級對話、發委託、頒發升階。
- 委託單改成**羊皮紙/通緝令**：委託人 + 一句劇情 + 危險星等(☠️) + 賞金 + 隨機怪物陣容預覽。
- 「出發 → 回報」小儀式。
- 美術用 **ComfyUI 生**：大廳底圖、公會長貓、委託單、階級徽章、冒險者證、公會裝圖示、戰利品。

## 限制 / 非目標

- **公會裝與公會戰力完全隔離**，主線平衡零影響（完工用 grep 佐證公會裝未被主線戰鬥引用）。
- **重用戰鬥核心**，不重寫戰鬥迴圈（ai-guide 慣例）。
- 新 Firestore 欄位/collection → 補 `firestore.rules` 白名單 + **提醒老闆手動貼 Console**。
- 不動主線打怪/地下城/世界王的任何數值。
- 舊 `adventurerXP`/等級：視為 legacy，本任務以新聲望/階級取代（保留舊欄位不刪，避免破壞歷史顯示）。

- [ ] 完成委託給聲望，聲望達標可升階，階級解鎖更高危險委託與商店層級。
- [ ] 公會專屬裝備可取得、裝備、強化，且**只在公會遠征戰鬥生效**。
- [ ] `grep` 佐證：公會裝/公會戰力函式**未被** MonsterBattle/dungeonDb/partyDb/worldBoss 等主線戰鬥引用。
- [ ] 公會長貓 NPC 有依階級的對話；委託單呈現故事+危險星等+隨機陣容。
- [ ] 美術資產到位（大廳/貓/委託單/徽章/證/裝備/戰利品）。
