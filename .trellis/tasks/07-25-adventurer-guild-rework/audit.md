# 冒險者公會完成度稽核（2026-07-27）

> 本文件以目前程式、測試、資產與路由為準；`implement.md` 原有勾選狀態已落後。
> 本輪只完成本機整合與驗證，沒有部署。

## 已完成

### 核心遠征

- `src/guild/` 已依 `domain / data / ui / db` 分層，沒有嵌入主線 `MonsterBattle`。
- 每日故事委託、危險度解鎖、隨機族系與多波怪物、HP 跨波延續、勝敗結案皆已完成。
- 單人與組隊都有獨立戰鬥流程、貓助攻、補給消耗、斷線續戰與獎勵結算。
- 清波後的迷路、惡劣天候、陷阱、休息泉事件已共用同一套規則；食水全空會強制撤退。
- 食物與飲水用主線金幣購入公會倉庫；單人出發或組隊備妥時自動各裝 6 份，庫存不足會導向商店。
- CAT 幣用於補給倉庫、農地、供水站升級；生產跨日／跨週離線累積，符合多數玩家每週只到場一次的使用節奏。

### 階級、裝備與經濟

- 六維遠征能力、5 裝備槽、6 品級、隨機詞綴、強化、分解、換裝與倉庫已完成。
- 獨立公會掉落表可產出共用材料、雜貨、公會裝、金幣與 CAT 幣。
- 雜貨估價、LUK 價值加成、公會商店及共用材料回寫主線庫存已完成。
- 聲望階級只負責身分與解鎖，不提供主線或公會戰力倍率。
- 稱號、雜貨圖鑑及 9:16 冒險者證下載／分享已完成。

### 場景與整合

- 大廳、公會長貓、羊皮紙、六階徽章、六區域背景、雜貨與角色美術均已存在。
- 公會長對話依階級改變，委託單包含故事、危險度、獎勵與陣容預覽。
- 射手會員入口與教練射手模式均指向 `GuildTestApp`。
- 未登入時可離線試玩，不寫 Firestore；登入者使用 `guildProfiles/{memberId}`。
- `firestore.rules` 已包含 `guildProfiles` 與 `guildTeamRooms` 規則。

- 原 PRD 先單人，實作已提前完成組隊遠征。

- 怪物數值由公會遠征自行產生；缺少專用 chibi 時可回退至既有正式怪物圖，不影響遊玩。

- 尚未做實機視覺 QA：手機尺寸、教練切射手模式、正式會員、訪客／登出狀態皆需人工點過。
- `docs/second_brain` 與 Obsidian 尚未同步。
- 舊 `src/components/member/AdventurerGuild.jsx` 仍保留為 legacy，但現行入口未引用；清除應另開低風險整理工作。

## 已知風險

- `guildTeamRooms` 目前允許任一登入者讀寫所有房間。功能可用，但正式公開多人模式前應改為房間成員／房主欄位級規則，重要結算最好移到可信任後端。
- `guildProfiles` 的獎勵與資產由 client 寫入，無法抵抗蓄意竄改。若遊戲經濟需要防作弊，應將遠征結算與請領改成 Cloud Function transaction。
- 冒險者證依賴執行時載入 html2canvas CDN；網路或 CDN 被阻擋時，遊戲仍可玩，但圖片下載／分享會失敗。
