# 射箭官網問題導向與 GEO 重整

## Goal

將既有貓小隊室內射箭場官網重整為「問題導向」的品牌與轉換網站。首頁維持完整、可信且有質感的品牌形象，讓不同來訪者從自己的問題出發，快速取得直接答案並前往對應分頁、預約或洽詢。

本次不是刪減內容，而是把舊首頁的完整資訊重新分配到首頁與專題頁，兼顧新客決策、裝備購買轉換、SEO 與 GEO（生成式引擎最佳化）。

品牌定位不得只停留在「新手友善、貓咪、休閒體驗」。官網必須用可驗證內容建立貓小隊的專業射箭場形象，讓搜尋引擎、生成式引擎與訪客清楚理解貓小隊同時具備入門教學、長期訓練、會員培養、器材評估、戶外進階與帶隊參賽能力。

貓小隊已完成自製射箭訓練與遊戲系統。這套系統是場館核心服務與重要差異，不是裝飾性 App，也不得只用少量截圖帶過。官網需完整介紹它如何把真實射箭轉化為可記錄、可挑戰、可共同遊玩的長期體驗。

### 品牌使命與教學理念

- 核心使命：「人人有箭射」。
- 「人人有箭射」定為正式公開的品牌使命標語，可用於首頁品牌理念與關於我們／教學理念內容，但不取代首頁描述地點與服務的搜尋導向 H1。
- 貓小隊不只是提供靶位的射箭場，而是讓一般人能安全接觸、理解並享受射箭生活的俱樂部與教學場域。
- 專業與娛樂不是對立：
  - 只想玩一次或休閒體驗的人，同樣可以學到專業、安全且正確的射箭知識。
  - 想長期練習的人，有系統、會員、戶外訓練與參賽路徑。
- 安全操作與正確觀念是所有體驗的基本內容，不因訪客只想娛樂就降低標準。
- 不以高磅數、分數、裝備價格、會員身分或比賽名次判斷一個人是否有資格享受射箭。
- 不將受傷、打臂或錯誤器材設定合理化為新手必經過程。
- 不鼓勵尚未確認興趣、練習頻率與適用規格的新手急著購買裝備。
- 專業教學的目的不是製造壓力，而是讓娛樂體驗更安全、更容易理解，也讓願意繼續的人有正確成長路徑。
- 比賽不是特定人群的專利；有意願的會員可以在適當準備與安全前提下，跟著俱樂部體驗完整參賽生活。
- 所有正式會員都可以表達參賽意願，不以分數、名次、得獎可能性或菁英資格作為篩選門檻。
- 出發前由教練確認的是基本安全、器材準備與完成賽程的能力，不是用成績淘汰想參與的人。
- 貓小隊不販售綁約課程，也不另外收取教練費；這是收費與服務方式，不代表沒有專業教學。
- 所有一般體驗費用已包含教練依現場狀況提供的教學與指導。
- 教學理念以人為本：每位學員的骨架比例、身體條件、活動方式、理解速度、動作回饋與學習節奏不同，不使用固定進度要求所有人做出完全相同的學習反應。
- 貓小隊自創一套完整的新手學習過程；結構化的是安全原則、觀察項目與能力順序，而不是強迫每位學員用相同時間完成相同步驟。
- 新手不用先知道該學什麼。教練會根據每次射箭呈現的狀態，逐項指出當下最需要理解或修正的部分，確認穩定後再推進下一項。
- 新手學習路徑目前確認為：
  1. 第一堂先建立新手射箭安全知識。
  2. 學習以保護新手安全為優先的射箭方式與器材操作。
  3. 依個人進度逐步學習轉臂。
  4. 依個人進度逐步學習安卡（固定靠位）。
  5. 依個人進度逐步學習起弓。
  6. 依個人進度逐步學習引弦。
  7. 進入正式撒放。
  8. 建立動作餘姿。
  9. 在動作控制與安全條件足夠時逐步升磅。
- 上述項目是能力推進順序，不代表固定一堂只教一項，也不承諾每位學員在相同堂數進入相同階段。
- 升磅不是獎勵或實力排名；由教練依控制能力、動作穩定與安全狀況判斷，不因學員主觀追求高磅而提前。
- 新手完成共同的安全與基礎控制後，另提供兩種學習路徑：
  - 體感派（直覺）：以身體感受、動作一致性與直覺建立命中方式。
  - 瞄準派（走弦式）：以走弦與較明確的瞄準基準建立命中方式。
- 兩條路徑都是正式且有效的射箭學習方式，不以其中一種代表更專業、更進階或更有天分。
- 兩條路徑的正式分流時機是在學員完成轉臂、準備逐步升磅時：
  - 學員會選擇使用射箭手套或指套。
  - 教練依護具選擇、個人感受、弓種興趣與學習反應推薦較合適的瞄準方式。
  - 路徑不是永久綁定；學員可以在適當教學下學習兩種方式。
- 一般教學傾向為：
  - 射箭手套較常銜接體感／直覺路徑。
  - 指套較常銜接瞄準／走弦路徑。
- 上述是推薦傾向，不是硬性規則；不得在官網寫成「使用某種護具就只能學某種瞄準方式」。
- 分流不是第一次來就必須自行選擇。新手先完成共同安全與基本控制，再由教練說明差異並協助選擇。
- 場館亦可教授傳統弓與美式獵弓，但新手通常先建議從競技反曲弓建立基礎。
- 先學競技反曲弓的理由不是弓種高低，而是傳統弓與美式獵弓較容易發生打臂，且存在需要事前理解的隱性安全風險；教練會先建立正確操作與風險辨識，再帶入其他弓種。
- 傳統弓需要說明的安全與操作差異：
  - 箭矢架在射手手上，需要養成經常檢查箭矢狀態的習慣。
  - 若箭矢已有損傷卻未發現，放箭時斷裂可能造成穿刺風險。
  - 羽片位置較靠近臉部，需要理解正確位置與放箭操作。
  - 拉距可能較大，操作不當時弓弦可能掃到臉部。
  - 握弓方式與競技反曲弓不同，不能直接照搬原本動作。
- 美式獵弓需要說明的安全與操作差異：
  - 外觀與部分操作看似接近競技反曲弓，但常見出力較大，不適合完全新手未建立控制能力就直接學習。
  - 斜弓操作會改變弓弦與手臂的相對位置，更容易發生打臂。
- 官網應將這些內容寫成「為什麼建議先建立競技反曲弓基礎」，並同時提供教練如何降低風險的處理方向，不製造恐慌。
- 安全頁需提醒：發現箭矢疑似損傷、操作位置異常或持續打臂時應立即停止放箭並請教練檢查，不讓學員自行勉強繼續。
- 官網應以尊重選擇的方式表達建議，不使用「不聽勸」等責備語氣；說明多數新手理解原因後會接受先建立競技反曲弓基礎。
- 完全新手若希望接觸傳統弓或美式獵弓，基本上可在教練現場評估、完整說明與直接指導下進行短時間體驗。
- 短時間體驗不等於首次練習全程使用；新手主要基礎時段仍以競技反曲弓為主，教練不會讓尚未具備控制能力的學員長時間使用風險較高或出力較大的弓種。
- 最終是否提供及體驗時間由教練依當天安全、器材與學員控制狀況判斷，官網不得承諾每位首次訪客都能指定弓種全程使用。
- 官網應直接回答「沒有賣課程、沒有另外收教練費，是否代表只是自己玩？」答案為否，並以教學流程、個別觀察與真實教學照片說明。
- 身體條件相關說明用於動作與器材適配，不做醫療診斷，也不宣稱可治療身體問題。

## Requirements

### 施工限制

- 規劃階段不得修改 `website/`、正式網站、正式網域或正式部署。
- 規劃經使用者確認後，先建立本地獨立備份／施工版本，不直接覆蓋原始網站。
- 保留既有技術架構、真實圖片、網址、SEO 頁面、metadata、結構化資料、sitemap、robots、預約系統與會員登入。
- 不直接發布 Production；完成後僅提供本機或 Preview。
- SimplyBook 已停止續約，不再是正式或備用預約入口。
- 新版公開官網須移除所有 SimplyBook 連結、備用入口與操作說明；個人預約與會員登入統一使用自建系統。
- 8 人以上團康不導向個人預約流程，改以 LINE／電話確認日期、需求與訂金。
- 是否刪除 repo 內 SimplyBook 歷史備份檔，於本地施工版本建立後依檔案引用與保存需求處理；不得影響原始網站備份。

### 內容策略

- 網站導覽以「訪客想解決的問題」為主，不只列出場館服務。
- 首頁維持乾淨、低複雜度的品牌形象，優先解決新客最重要的問題，不重新堆回二十多個完整內容區塊。
- 首頁使用清楚的需求分類區塊，讓訪客快速辨識自己的情境並點入對應分頁；完整制度、玩法、專業證據與長篇回答由分頁承接。
- 首頁每個區塊只保留完成判斷所需的最少資訊，避免功能清單、過量數字與多組競爭 CTA。
- 每個重要問題必須提供：
  - 直接、具體、可獨立理解的答案。
  - 適用對象與不適用情況。
  - 下一步行動與描述性連結。
  - 對應的預約、洽詢或深入閱讀方向。
- 允許新增多個專題分頁，以完整承接首頁內容。
- 建立裝備參考選購介面，協助訪客理解弓種、慣用手、拉距、磅數、箭矢、預算與常見錯誤，最終引導現場評估或裝備購買。
- 第一次體驗者應被明確告知不必先購買裝備，先體驗與試射能降低買錯風險。
- 裝備服務的核心原則是「先確認喜歡射箭、願意持續，再談購買」，不鼓勵第一次接觸就買整套器材。
- 官網需誠實說明提早購買的風險：尚未確認興趣、練習頻率、慣用手、拉距、適合磅數及目標，容易買錯或最後將弓長期閒置。
- 裝備服務流程：
  - 先使用場館器材體驗與練習。
  - 教練觀察身高、拉距、慣用手、動作、適合磅數、用途與預算。
  - 確認訪客願意持續練習後，再協助代購或訂購適合的裝備。
  - 官網不建置可讓訪客跳過評估直接購買弓具的自助商城。
- 建立「新手常見錯誤觀念」內容群，使用直接答案糾正可能造成受傷、挫折或錯誤消費的觀念。
- 明確糾正：「射箭時手臂被弓弦打到是正常的」是錯誤觀念。經常打臂不應被視為正常代價，應檢查站姿、持弓、手肘方向、放箭動作、護具與器材設定，並由教練協助修正。
- 醫療或傷害相關內容僅提供射箭安全與動作教育，不做醫療診斷；若已有明顯傷勢應停止練習並尋求適當處理。
- 團康頁需從主辦人的問題出發，說明射箭團康能解決的活動規劃問題、優點、限制、流程、價格、場地容量與洽詢方式。
- 專業性必須成為首頁核心支柱，而不是接近頁尾的附帶內容：
  - 中華射箭協會 C 級教練。
  - 系統化、可長期持續的訓練內容。
  - 正式學籍與會員培養。
  - 戶外進階訓練。
  - 校園及相關單位射箭教學經驗。
  - 每年帶領學員外出參加射箭比賽。
  - 真實比賽、教學、戶外訓練及活動照片作為證據。
- 「每年帶隊參賽」是持續性能力，不得弱化成偶爾支援校外活動。
- 自製射箭系統必須成為首頁核心支柱與獨立完整分頁：
  - 適合一個人射箭，不需要等待同伴也能有清楚目標。
  - 適合親子共同完成任務與培養持續練習動機。
  - 適合情侶一起打怪、合作或比較成果。
  - 將真實射箭分數連接到打怪、成長、裝備升級與目標完成。
  - 提供長期累積與下一個練習目標，避免體驗結束後失去方向。
  - 使用真實系統畫面、實際玩法與可驗證功能介紹，不以抽象行銷詞取代說明。
- 第一次來、尚未取得正式會員帳號的訪客，即可直接使用主要打怪玩法。
- 正式會員帳號用來保存個人成長、裝備、成就與長期紀錄。
- 系統頁必須清楚區分「首次體驗可使用的玩法」與「正式會員可長期保存的內容」，避免訪客誤以為一定要先入會才能玩，也避免誤以為訪客紀錄會永久保存。
- 官網只介紹與展示系統，不修改 Firebase、會員資料、預約系統或遊戲邏輯。
- 以低干擾方式介紹同品牌另有獨立的貓砂購物官網；此內容不得搶走射箭主體、干擾預約轉換，或讓搜尋引擎／AI 將射箭官網主要實體誤判為寵物用品店。
- 射箭場提供實體接觸優勢：訪客到場時可以親眼查看相關產品，並取得現場真人介紹，再前往獨立購物官網選購。
- 射箭官網不建立寵物用品商城、不承接完整商品目錄與結帳；使用清楚標示的跨站連結導向專門購物官網。
- 相關資訊只作低權重品牌旁註，不建立「貓店長生活補給角落」等可能被視為主要內容的完整區塊。
- 只在貓咪介紹尾端、到店資訊或 Footer 附近出現一次簡短文字連結；不放在 Hero、主導覽、射箭價目表或主要 CTA。
- 不為貓砂／餐包建立獨立頁、FAQ、結構化資料、Offer、商品清單、metadata 關鍵字或 sitemap 項目。
- 不在多頁重複、不使用 H1～H3 標題、不刻意累積寵物用品關鍵字，避免 SEO／GEO 主題偏移。
- 可見文字無法保證完全不被搜尋引擎或 AI 讀取；目標是降低語意顯著性，使其維持次要品牌資訊。
- 跨站連結應明確告知將前往另一個購物網站，避免混淆服務與網域。
- 獨立購物網站使用乾淨連結 `https://www.catgroup.com.tw/collections/%E6%96%B0%E5%93%81%E6%8E%A8%E8%96%A6`，不得保留搜尋引擎附加的 `srsltid` 追蹤參數。
- 連結目的頁目前標題為「貓小隊貓砂系列」，購物網站品牌為「貓小隊 Catgroup」。

### 已確認的訪客問題入口

- 第一次射箭，我不知道要學什麼。
- 我想開始固定練習。
- 我想買第一套裝備，但不知道該注意什麼。
- 我已經有裝備，想找地方練習。
- 我想帶小孩、伴侶或朋友一起來。
- 我要安排公司、部門或小型團體活動。

完整問題庫仍需在規劃階段擴充，涵蓋新手、價格、器材、兒童、單人、團體、長期訓練、會員、戶外場、交通、預約、安全與貓咪等決策。

### SEO 與 GEO

- 保留所有既有 SEO 情境頁 URL，不刪除、不改名、不合併。
- 每個重要搜尋／生成式問答意圖應有清楚的主要承接頁，避免多頁互相競爭同一問題。
- 每頁開頭應用純文字直接說明：這是什麼、適合誰、位於哪裡、價格或資格、如何進行下一步。
- 關鍵事實必須以可見文字呈現，不可只存在圖片、互動元件或 JSON-LD。
- 問題使用自然語言標題，答案先給結論，再補充條件、證據與下一步。
- FAQ、LocalBusiness／SportsActivityLocation、Offer、Breadcrumb 等結構化資料必須與畫面內容一致。
