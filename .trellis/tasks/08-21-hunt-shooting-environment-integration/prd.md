# 狩獵場外射擊設定接入

## Goal

讓玩家在狩獵開始前設定的實際射擊距離與靶紙，成為單怪／複數、單人／組隊狩獵共同的戰鬥條件：畫面顯示正確靶紙、只能輸入該靶紙存在的分數，並依較高難度給予一致且可驗證的遊戲加成。

## Confirmed facts

- 專案已有共用靶紙幾何與計分來源 `targetFace.js`，包含 122cm 全靶、17cm 半靶、原野靶與三聯靶等格式。
- 專案已有世界王距離／靶紙倍率規則；目前狩獵草稿 `freeHuntEnvironment.js` 已直接重用該資料源，距離範圍為 5–18m。
- 世界王現行權威規則為：距離倍率 × 靶紙倍率只套用玩家每箭傷害，不放大掉落、經驗或次數收益；三聯靶每張最多 2 箭。
- 世界王距離倍率為 `sqrt(max(5m, distance) / 5m)`，上限 ×2 並取小數二位；目前可選距離為 5–18m。
- 世界王靶紙倍率為：17cm 半靶 ×1.0、122cm 全靶 ×1.2、原野靶 ×1.4、40cm 三聯靶 ×1.5。
- 狩獵不得加入弓種倍率；草稿中的傳統弓 ×2 必須移除。弓種可保留為射擊紀錄／裝備資訊，但不參與環境傷害倍率。
- 既有 `TargetFaceInput` / `TargetFaceOverlay` 可顯示並點擊實際靶面；`getTargetScoreLabels()` 可產生各靶紙合法分數。
- 原本單怪狩獵已出現距離／靶紙選擇 UI；組隊單怪已有每位成員獨立的 `huntDistanceM` / `huntTargetFmt` 欄位。
- 複數怪物戰鬥目前仍用固定 `X,10…1,M` 按鈕，尚未依個人靶紙限制可點分數與顯示對應靶面。
- 組隊成員可能使用不同距離與靶紙，因此加成與合法分數必須以成員的鎖定快照計算，不能只使用房間共用值。

## Requirements

- 狩獵準備畫面是戰鬥條件的唯一設定入口：玩家進場後先選距離、靶紙與輸入方式，按下確認／開始時才產生每位玩家的版本化快照並鎖定；正式戰鬥中只能查看、不能更改。
- 組隊模式由每位成員各自選擇並確認自己的距離、靶紙與輸入方式；隊長開始戰鬥後，所有成員快照一併鎖定。
- 組隊中所有仍在房間內的成員都必須完成設定確認，隊長才能開始；未確認者不得被自動套用預設值或由隊長強制略過。
- 準備畫面與隊長開始按鈕需明確列出尚未確認的成員；後端開始交易也必須驗證全員已確認，不能只依賴 client disabled 狀態。
- 組隊成員列表只公開每人的已確認／未確認狀態；距離、靶紙、輸入方式與倍率只對本人顯示，隊長也不能查看或修改他人的詳細設定。
- 每次進入準備畫面時預填該玩家上次使用的距離、靶紙與輸入方式，但每一場都必須重新按確認；記憶值不得自動把玩家標成 ready。
- 玩家確認後、隊長開始前可取消確認並修改；任何修改都必須將該玩家恢復為未確認，修改完成後需重新確認。
- 隊長開始戰鬥的權威交易會一次鎖定全員快照；開始後所有設定、取消確認與修改請求都必須被拒絕。
- 斷線重連必須沿用房間內原有快照，不得重新讀取玩家後來修改的個人設定。
- 支援既有單怪／複數怪物，以及單人／組隊狩獵流程。
- 同一套準備、確認、鎖定、顯示、合法分數與倍率規則必須覆蓋：單人指定單怪、組隊指定單怪、單人複數怪物、組隊複數怪物。
- 每位玩家保存自己的距離與靶紙快照；組隊玩家可互不相同。弓種可隨射擊紀錄保存，但不參與倍率。
- 準備階段可選「靶面輸入」或「點擊分數」；戰鬥中只顯示已鎖定的單一輸入方式，不提供切換。
- 選靶面輸入時，戰鬥 UI 顯示對應靶紙並以落點計分；選點擊分數時，只顯示該靶紙合法的分數按鈕。
- 靶面點擊與分數按鈕雖不會同時出現，但必須產生相同、可驗證的標準化箭矢資料。
- 三聯靶保留每張最多 2 箭限制，前後端都要驗證。
- 距離與靶紙倍率完全沿用世界王參數，且只套用該玩家每箭傷害；掉落、經驗與每日次數收益不放大。
- 傷害加成必須由權威端依鎖定快照重算，client 顯示不可成為權威來源。
- 舊房間或缺少新欄位的存檔需有安全預設值並可繼續遊戲。
- 手機 360×640 與 390×844 可完整操作靶面、分數、撤回及送出。

## Acceptance Criteria

- [ ] 玩家進入準備畫面後可選距離、靶紙與輸入方式；按確認／開始時產生版本化快照，正式戰鬥後不可修改，斷線重連沿用原快照。
- [ ] 組隊每位成員可獨立選擇並確認；所有在房成員確認前，client 與後端都禁止隊長開始，並顯示未確認名單。
- [ ] 隊伍只看得到確認狀態；個人射擊環境與倍率不會顯示給其他成員。
- [ ] 下次進場會預填上次選擇，但仍處於未確認狀態，直到玩家明確確認本場設定。
- [ ] 隊長開始前可取消確認、修改並重新確認；隊長開始後 client 與後端都拒絕任何設定變更。
- [ ] 單怪與複數、單人與組隊都讀取相同環境模型。
- [ ] 四種狩獵入口都具有相同的設定確認與鎖定語意，不因戰鬥 UI 不同而分叉規則。
- [ ] 靶面模式只顯示與快照一致的靶紙，不顯示分數按鈕。
- [ ] 點擊分數模式只顯示該靶紙合法分數，不顯示可點靶面；非法分數在 client 與 server 都被拒絕。
- [ ] 靶面點擊與按鈕輸入的計分、傷害結果一致。
- [ ] 每位組隊成員的倍率與靶紙獨立計算。
- [ ] 距離、靶紙與合成倍率在進場前及戰鬥中清楚顯示；弓種不顯示任何傷害倍率。
- [ ] 三聯靶每面 2 箭限制在重連與重送後仍成立。
- [ ] 舊資料使用明確預設值且不造成 room_not_found、invalid score 或卡房。
- [ ] 純函式、adapter、權威 Functions contract、UI contract 與手機 viewport 驗證通過。

## Out of scope

- 修改世界王既有倍率表。
- 新增靶紙美術格式。
- 部署或正式環境資料遷移，需等實作與驗證完成後另行確認。
