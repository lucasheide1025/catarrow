# 新版訪客打怪遊戲 UI 重設計

## Goal

重新設計新版訪客 Arcade 的核心 UI，讓第一次來射箭的訪客感受到這是一款現代手機遊戲，而不是表單或舊學籍系統，同時維持快速上手與現場射箭操作效率。

## Users

- 第一次到射箭場、掃 QR 後使用手機遊玩的訪客。
- 親子、小朋友、朋友團體與不熟悉 RPG 數值的休閒玩家。
- 已建立本機 Arcade profile、回來繼續冒險的訪客。

## Requirements

- 手機優先，拇指可操作；主要動作需清楚、夠大且不被裝飾干擾。
- 視覺要更像現代遊戲：有世界觀、場景層次、角色焦點、狀態 HUD、清楚的主次動作與回饋。
- 保留「童話冒險 × 貓咪弓箭手」品牌，但減少目前大量米色表單卡片與平均排列造成的網頁感。
- 首次流程仍需在 10～20 秒內完成暱稱、同行貓與開始冒險。
- 回訪大廳優先呈現「立即開始／繼續冒險」、三種地下城與角色進度；房號加入、競技場、商店、統計等次要功能不可搶走主線焦點。
- 三種地下城必須有明顯不同的環境氣氛與難度辨識，但仍屬同一套設計系統。
- 戰鬥畫面需讓怪物、玩家／同行貓、HP、本回合目標、分數輸入與主要攻擊操作一眼可辨。
- 保留既有資料、路由、單人／組隊／競技場／商店功能與 Local First 行為；本任務以呈現層重構為主。
- 動畫需服務操作回饋並尊重 `prefers-reduced-motion`，避免長時間阻塞射箭節奏。
- 支援窄螢幕、安全區、可讀對比、清楚 focus 狀態與基本無障礙語意。
- 組隊冒險怪物 HP 改為 `原始 HP ×（1 + 開戰玩家人數）`；2／4／8 人分別為 ×3／×5／×9。
- 組隊玩家開戰時每人 100 HP；怪物在玩家回合後仍存活時，對所有存活玩家各造成一次完整攻擊傷害。
- 組隊全員 HP 歸零才團滅；Boss 大招也使用全體 HP 傷害，不再只以抽象士氣作為唯一失敗條件。
- 決鬥 HP 上限依開戰人數鎖定：3 箭以 2 人 80 HP 為基準，每多 1 人 +20；6 箭以 2 人 130 HP 為基準，每多 1 人 +30。
- 組隊與決鬥的開戰 HP 快照在重整、重連與房主交接後必須維持一致，不得按當下在線人數重新計算。
- 冒險結算分享卡需改為現代遊戲「冒險檔案」構圖：直式深色面板、大型評級／稱號、五軸表現雷達圖、同行貓與三項核心戰績，套用貓咪射箭魔法機台風格。
- 分享卡必須沿用既有 Canvas／Web Share／PNG 下載流程並保持離線可產生，不依賴新伺服器或外部圖片服務。

## Acceptance Criteria

- [x] 首次訪客頁與回訪大廳採用一致的新遊戲視覺系統。
- [x] 首屏具有清楚的角色／場景焦點和單一最主要動作，不再像多張同權重表單卡。
- [x] 三種地下城可在不閱讀長文時靠色彩、場景與標籤分辨。
- [x] 手機 390px 寬度下，主要按鈕與必要資訊無水平溢位或遮擋。
- [x] 現有 Arcade 流程與 155 項既有測試保持通過，新增必要的 UI 契約測試。
- [x] Production build 通過。
- [x] 組隊怪物 HP、每位玩家 HP、全體怪物反擊與全員團滅條件有純函式及房間整合測試。
- [x] 決鬥 2～8 人、3／6 箭的 HP 上限符合鎖定公式，重整後不漂移。
- [x] 單人與組隊結算都可產生新版 1080×1620 冒險檔案分享卡，雷達值有 0～100 正規化與缺資料 fallback。

## Out of Scope

- 更改玩家射箭傷害公式或獎勵經濟（本次明確指定的多人 HP／怪物反擊除外）。
- 把 Arcade 接回舊 GuestApp／學籍系統。
- 重做所有怪物與貓咪原始美術資產。
