# 貓咪三型戰鬥定位重製

## Goal

重新設計貓貓陪練的治療型、攻擊型、防禦型，使三型都能配合新版卡片、異常狀態與裝備專精形成有吸引力且可辨識的玩法，改善目前玩家幾乎只選攻擊型的問題。

## Confirmed Facts

- 九隻貓依固定角色分成三組：大娘／哥哥／妹妹為治療技能，妞妞／哈吉／寶寶為攻擊技能，悠悠／小安／點點為防禦技能。
- 現行技能是機率觸發：治療型回 HP、攻擊型追加傷害、防禦型增加下一次反擊減傷。
- 三型仍會做普通協戰攻擊，因此攻擊型同時擁有較高 ATK 與直接追加傷害，短期收益最直觀。
- 治療在滿血時沒有價值；防禦在未受高傷、怪物被控場或護盾足夠時也容易浪費。
- 新卡片系統已有開場護盾、回合恢復、治療加成、反傷、減傷、異常施加與抗性。
- 裝備專精「應援」可提升貓咪攻擊與治療，但現行沒有對防禦型提供對等的專屬成長維度。
- 貓咪有個體 build、等級、羈絆、裝備與自身 HP／DEF，不需要新增第四種養成資源。

## Product Intent

- 三型不應只靠相同技能換顏色或放大數字；每型需要不同的戰術理由。
- 新設計應與卡片、專精、護盾及異常狀態互動，而不是建立另一套孤立系統。
- 手機戰鬥介面必須清楚顯示貓咪本回合做了什麼，且避免增加常駐操作負擔。
- 三種類型都必須能實際推進擊敗怪物的進度，不能讓治療型與防禦型只在玩家已經受傷時才有價值。
- 治療型須能對怪物施加異常狀態，使裝備治療型貓咪的玩家即使與怪物實力不對等，也能透過持續效果造成實際傷害。
- 防禦型須能提供玩家護盾、減傷及暫時提升 ATK／DEF，將防守轉化為後續作戰能力。
- 防禦型採「守護反攻」循環：每回合建立護盾；護盾存在時提供 DEF；護盾實際吸收怪物傷害後，依吸收量在下一回合提供有上限的 ATK 強化。
- 防禦型的強化技能可提供大型護盾、提高減傷或一次性防倒地，但不得形成永久無敵循環。
- 治療型的傷害異常採混合公式：以貓咪能力為基礎，再加上怪物最大 HP 的小比例，並依一般怪／王類設定每回合上限。
- 第一階段在自由狩獵、組隊狩獵、單人地下城與組隊地下城完整實裝；世界王使用限制版；決鬥暫不套用新版能力。
- 世界王限制版降低最大 HP 比例傷害並設每回合總上限；完全格擋／防倒地改為高額減傷；全隊效果有隊伍總上限。
- 完整保留既有貓咪等級、經驗、羈絆、裝備、九隻分組及個體 build；只替換戰鬥技能模型，不重置或退款養成。
- 羈絆等級（現行 0–50）是新版能力核心成長軸：提高每回合基礎效果、強力技能威力與保底前觸發率；不得只顯示在面板。
- 羈絆不縮短第四回合保底、不突破各模式傷害／護盾／減傷上限，也不使完全格擋或防倒地增加無限次數。
- UI 必須在角色預覽及詳情清楚顯示目前羈絆對技能的實際加成與下一級提升。
- 「貓貓陪練」主頁與詳情頁須配合新系統整體重設；目前資訊架構與視覺不足以解釋三型循環及九隻差異。
- 新頁面以手機為主，風格要更可愛、有角色感與輕量動畫，但不可犧牲文字可讀性或造成長頁面反覆捲動。
- 玩家選貓前須能看懂：類型核心循環、每隻三項特性、每回合基礎效果、強力技能與保底、卡片／專精聯動、各模式限制。
- 首頁優先顯示目前陪練貓、快速切換與三型戰術入口；完整數值、養成與技能細節放入詳情或抽屜，避免一次塞滿。
- 重用現有九隻貓肖像與 CatAnimator 動畫資產；需要新增的視覺以可愛戰術徽章、狀態圖示、卡片式動效為主。
- 主視覺採「可愛圖鑑收藏＋戰術配置」混合：上半部是目前同行貓咪的陪練房、大圖、待機動畫與台詞；下半部以治療／攻擊／防禦三個彩色戰術分頁呈現九隻角色。
- 三型入口使用玩家能理解的新戰術名稱：侵蝕治療、狩獵攻擊、守護反攻；仍保留治療型／攻擊型／防禦型副標籤，避免舊玩家困惑。
- 每張角色卡先顯示被動、強力技能、聯動三個徽章；完整公式與模式限制點入詳情查看。
- 換貓採兩步快速流程：點角色卡只切換預覽，上方陪練房即時更新；底部固定按鈕確認攜帶。成功後播放短動畫與專屬台詞，不使用多餘確認視窗。
- 詳情入口提供完整技能、養成與裝備內容；已同行角色顯示「陪練中」且不顯示重複操作。

## Initial Design Direction

- 攻擊型：維持爆發／追擊核心，偏向利用怪物異常、破盾或殘血條件擴大輸出。
- 治療型：從純隨機補血提升為「續航＋異常侵蝕」。除了恢復、淨化或溢補轉護盾，也能對怪物施加會造成實際傷害的異常；核心價值是讓弱勢玩家仍可穩定磨損高防禦怪物。
- 防禦型：從一次減傷提升為「護盾守護＋蓄勢反攻」。提供護盾、減傷、暫時 ATK／DEF 強化，必要時可攔截重擊或致命傷。
- 三型初步戰術循環：攻擊型快速擊殺；治療型靠續航與異常越級消耗；防禦型承受攻擊並累積能力後反攻。
- 個別貓咪仍以現有 build 差異區分穩定、頻率與爆發，不重分九隻角色。
- 九隻貓不能只靠數值倍率區分；每隻都需要三項可辨識特性：一個每回合／條件被動、一個專屬強力技能、一個偏好的卡片或專精聯動。
- 同型三隻共享該類型的核心循環，但透過三項特性形成穩定、頻率、爆發或不同戰術分支。
- 組隊效果採主人優先：每回合基礎效果與完整強化只作用於主人；強力技能觸發時，才額外提供較弱的全隊支援。
- 治療型強力觸發可讓全隊小幅恢復或淨化一項異常；防禦型可提供全隊小型護盾／短暫減傷；攻擊型可對怪物施加全隊可利用的破防／易傷。
- 治療型三隻各有專屬異常：大娘「藥蝕」（持續傷害＋抑制怪物治療）、哥哥「虛弱」（較低持續傷害＋降低怪物 ATK）、妹妹「脈衝感染」（短時高頻，觸發時追加即時傷害）。
- 貓咪專屬異常進入共用怪物異常系統，可與卡片異常並存，但遵守主要狀態數量、刷新及疊層上限。
- 攻擊型個體定位已確定：妞妞「精準獵手」（高品質命中、弱點穿甲、異常追擊，聯動精準／穿甲）；哈吉「連擊獵手」（有效命中累積、多段攻擊、異常累積，聯動爆擊／異常）；寶寶「終結獵手」（殘血增傷、大型終結、擊倒回饋，聯動終結／獵王／破盾）。
- 防禦型個體定位已確定：悠悠「均衡護衛」（穩定護盾、護盾期間小幅 ATK／DEF、全隊護盾，聯動護盾／減傷／反傷與堅韌）；小安「生命堡壘」（最大 HP 護盾、低血強化、每場一次防倒地，聯動 HP／治療／護盾與營養／守勢）；點點「鐵壁格擋」（吸收傷害轉下回合 ATK、完全格擋與強化反攻，聯動反傷／DEF 與守勢／堅韌）。
- 治療型個體定位已確定：大娘「守護藥師」（穩定恢復、溢補轉盾、藥蝕與全隊小恢復，聯動治療／回復／護盾及睡飽／營養）；哥哥「調律醫師」（治療兼減輕異常、虛弱降攻、淨化與全隊抗性，聯動抗性／毒抗／減傷及免疫）；妹妹「脈衝醫師」（高頻治療、脈衝感染即時傷害、引爆傷害型異常，聯動毒／燃燒／流血及應援）。
- 全隊效果需設不可重複疊加或隊伍總上限，避免四隻同型貓造成失控。
- 每種類型每回合固定提供基礎效果；強力技能另以機率觸發。
- 強力技能依個體分成高頻約 35%、均衡約 25%、爆發約 18% 的初始觸發率；個體既有 `skillChance` 用於微調。
- 若連續三回合未發動強力技能，第四回合保證觸發，觸發後重新計數；保底狀態須能隨續戰快照保存。

## Open Questions

- 已決定：每回合固定有基礎效果＋機率強力技能，最晚第四回合保底觸發。
- 已決定：主人獲得完整效果；只有強力觸發會給全隊弱化版支援。
- 貓咪與卡片、專精的聯動應採通用規則，或讓各型對特定效果有額外轉換。
- 已決定：九隻貓各自具有三項特性，並包含自己的卡片／專精聯動偏好。
- 是否允許防禦型攔截致死傷害，以及每場次數限制。
- 治療型施加的傷害異常應按怪物最大 HP、玩家／貓咪能力，或兩者混合計算；需要避免越級有用卻變成對王固定百分比秒殺。
- 已決定：採貓咪能力＋怪物最大 HP 小比例的混合公式，王類使用較低比例與更嚴格上限。
- 已決定：DEF 在護盾存在期間生效；ATK 由護盾實際承傷後觸發，只持續下一回合並設上限。
- 已決定：完整保留既有養成與分組，只替換戰鬥技能模型。
- 已決定：採可愛圖鑑收藏＋戰術配置混合的主視覺方向。
- 已決定：主頁兩步快速換貓，角色卡預覽後由固定按鈕確認。

## Acceptance Criteria

- [ ] 九隻貓保留全部既有養成與分組，資料無需遷移或退款。
- [ ] 相同貓咪在較高羈絆時，其基礎效果與強力技能有可測量提升；觸發率仍受 cap 與第四回合保底約束。
- [ ] 三種類型每回合均有可見基礎效果，且強力技能最晚第四回合保底觸發。
- [ ] 治療型三隻可用專屬異常造成實際傷害；混合公式對一般怪、王類與世界王分別受上限約束。
- [ ] 防禦型護盾、護盾期間 DEF、吸收量轉次回合 ATK、致命攔截／格擋均按個體規則生效且不可永久循環。
- [ ] 攻擊型三隻的精準、連擊、終結條件與卡片／專精聯動可被自動化測試區分。
- [ ] 組隊中主人吃完整效果，強力技能才提供弱化全隊效果；同類效果遵守隊伍總上限。
- [ ] 自由狩獵、組隊狩獵、單人地下城及組隊地下城使用完整新版；世界王使用限制版；決鬥維持舊版。
- [ ] 貓咪技能狀態、保底計數、護盾與反攻增益可隨中途離場／重整正確恢復。
- [ ] 戰鬥演出明確顯示基礎效果、強力發動、異常傷害、護盾吸收、全隊支援與增益到期。
- [ ] 貓貓陪練主頁在手機上提供目前同行、三型分頁、九隻預覽、兩步換貓與詳情入口，主要操作無需反覆長距離捲動。
- [ ] 每張角色卡可在第一層看懂被動、強力技能與聯動；完整公式與模式限制在詳情中有中文說明。
- [ ] 頁面使用既有貓咪圖片及動畫，以可愛圖鑑＋戰術配置呈現，並符合 reduced-motion 與可讀性要求。
- [ ] 相關純函式、單人 reducer、組隊／地下城權威結算、續戰快照、UI 契約測試及 production build 通過。

## Out of Scope

- 不更換九隻貓的角色形象與美術設定。
- 不新增第四種貓咪型態。
- 不重做貓咪村莊、取得方式或養成素材經濟。
- 規劃階段不直接修改戰鬥程式。
