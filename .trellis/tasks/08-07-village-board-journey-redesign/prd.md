# 貓貓村探索地圖重製：7 張直線旅程地圖

## Goal

把現行「28 格固定環形棋盤」的探索地圖（villageBoard）重製為 **7 張直線旅程地圖**：

1. **7 張地圖**＝現行 7 個採集模式（星屑礦坑／月芽農田／霧潮港口／巡林狩獵場／喧鬧市集／古罐倉庫／藏金靶場），每張對應一個家族經濟體。
2. 每張地圖＝一趟**旅程**：用 seed **隨機生成 100~200 格的蜿蜒路線**（橫向捲動＋縱向蜿蜒），每次進場/完成後佈局都不一樣。
3. **每張地圖獨立保存玩家進度**（旅程 seed + 位置），隔天可繼續同一趟旅程。
4. 15 顆骰子**全地圖共用**（每日補滿、不囤積，規則不變）。
5. 到達終點 → **終點 Boss**（射箭挑戰）→ 打完發大獎 → 該地圖旅程完成、標記可重刷（換新 seed 重新生成路線）。
6. **射箭只剩「怪物格」與「終點 Boss」**；採集/挖礦格**不射箭**，踩到直接給資源，搭配演示畫面（純動畫 A 或三選一 C，**隨機擇一**）。
7. 怪物沿用既有生成圖片（鬼怪/山林已重製立繪、其餘用現有資產），**不另做 SVG**。
8. 新增格子：營地／強化／貓夥伴／陷阱／捷徑／市集／風景（＋終點 Boss），保留既有 12 種的大部分。
9. 組隊：共享棋子，**吃房主的旅程進度＋房主骰子**。

## Confirmed Facts（作者 2026-08-07 定案）

- 現行 `GATHERING_SITES` 有 **7 個採集點**（六大族＋寶箱族），`BOARD_MODES` 隨之為 7。
- 終點運作：抵達終點 → Boss 射箭挑戰 → 大獎 → 完成可重刷（進度清空、換新 seed）。**Boss 無失敗概念**，按 6 箭分數帶 S/A/B/C 判定獎勵大小。
- 骰子：15 顆全地圖共用。
- 採集演示：**A（純動畫 1.5~2s 結算）或 C（三選一採集點），每次踩到隨機擇一**。
- 路線長度：**100~200 格，每次隨機生成排列**（seed 控制）。
- 組隊吃房主進度與骰子；採集 C 三選一**各隊員自己選、各自結算**。
- 市集格第一期**佔位**（小機率金幣＋「市集整修中」），第二期做完整市集。

## Requirements

### 地圖與路線

- 7 張地圖各有一趟「旅程」狀態：`{ seed, pos, length, clears }`，存於 `members/{id}.villageBoard.maps.{mapId}`。
- 路線由 seed 決定：長度（100~200 隨機）、格子排列（加權隨機）、蜿蜒路徑幾何（座標序列）。**同一 seed 產生完全相同的路線**（client 顯示與 server 結算一致）。
- 旅程未完成期間佈局固定；完成後換新 seed 重新生成。
- 骰子移動 1~6；`pos + 步數 > 終點` 時停在終點（觸發終點 Boss），不折返。

### 格子（保留 + 新增）

- 保留：素材／挖礦（改不射箭）／怪物（射箭）／寶箱／箭露／金幣／扭蛋幣／藥水／貓羈絆／命運／機會／起點。
- 新增：**終點 Boss**（射箭挑戰，S/A/B/C 大獎）、營地（本趟後續格子獎勵 +X%）、強化（下一射箭格 ×2）、貓夥伴（本趟隨行貓加成）、陷阱（後退/損失）、捷徑（前進 3~5 格）、市集（花村資源買 BUFF/骰子，可列第二期）、風景（純 flavor＋微獎勵）。
- 格子機率權重：素材/資源格佔多數，事件與特殊格適量；每張地圖可用不同調性（依家族世界觀）。

### 射箭與採集

- **射箭格**（怪物／終點 Boss）：射 6 箭，完成度 S/A/B/C 決定獎勵；沿用 `TargetFaceOverlay` 完成度計分，不看能力值。
- **採集格**（挖礦）：不射箭。踩到時隨機擇一演示：A 純動畫（1.5~2 秒採集演出→獎勵噴出）或 C 三選一（3 個採集點各含不同報酬，選完結算）。組隊：C 由**各隊員自己選、各自結算**；A 房主執行、隊員等待；計時＋自動隨機選保護。
- 怪物圖片沿用既有資產（`public/monsters-battle/` 或現有機制），不新增 SVG。

### 進度與目標

- 地圖選單顯示每張地圖的進度（位置/總長 %、完成次數、可玩狀態）。
- 抵達終點 Boss 並獲勝 → `clears+1` → 村目標 `board_laps` 進度 +1（沿用現有 hook）。
- 骰子 0 時不能骰；每日 `ensureDailyDice` 補滿 15 不變。

### 組隊

- 共享棋子、吃房主所選地圖的旅程狀態與骰子；隊員可 0 骰加入。
- 斷線重連＋中途存檔（沿用 `villageBoardTeamDb` 現有模式，改成吃房主 per-map 旅程）。

## Acceptance Criteria

- [ ] 7 張地圖各自獨立旅程：`villageBoard.maps.{mapId}.{seed,pos,length,clears}` 正確讀寫；隔天回來位置保留。
- [ ] 同一 seed 生成的路線（長度、格子、座標）確定性一致；長度落在 100~200。
- [ ] 骰子 15 顆全地圖共用；每日補滿邏輯不變；用罄不能骰。
- [ ] 抵達終點觸發 Boss 射箭挑戰；**按分數帶 S/A/B/C 判定獎勵**（無失敗）、`clears+1`、旅程重置換新 seed；村目標 `board_laps` 進度正確。
- [ ] 採集格不射箭；踩到隨機演示 A 或 C，獎勵正確結算；組隊 C 各隊員各自選、各自結算，等待保護不卡房。
- [ ] 怪物格射箭、完成度 S/A/B/C 獎勵正確（沿用 `scoreToBand`/`rollTileReward` 純函式或等價重寫）。
- [ ] 新格子（營地/強化/貓夥伴/陷阱/捷徑/市集/風景）效果正確且可被事件/狀態疊加。
- [ ] 組隊共享棋子吃房主旅程；斷線重連可恢復。
- [ ] Firestore rules：`villageBoard.maps` 欄位進 members 白名單（hasOnly）。
- [ ] 地圖選單＋旅程 UI（橫向捲動＋縱向蜿蜒）可用；`prefers-reduced-motion` 尊重。
- [ ] 全測試（含 boardData 純函式單元測試）＋ production build 通過。

## Out of Scope

- 不改變骰子每日補滿 15 的規則。
- 不改變六族素材階級上限機制（建築 stage 鎖 T1~T5）。
- 不改採集任務（catVillageGathering）本身；只改探索地圖。
- 不新增怪物美術（沿用現有資產）。
