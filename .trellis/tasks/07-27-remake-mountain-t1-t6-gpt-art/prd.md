# 山林族 T1-T6 GPT 立繪重製

## Goal

沿用鬼怪族已驗證的 Tier × Encounter 雙軸與半 Q 戰鬥規格，完整重製山林族 T1～T6 共 36 隻怪物的卡圖、戰鬥立繪與身分文案，使每階強度、普通／小王／大王差異以及山林族共同世界語言都能一眼辨識。

## Confirmed Facts

- 正式資料已有 36 個固定 stable IDs：6 階 × 每階 6 隻。
- 每階固定為 3 隻普通怪、2 隻小王、1 隻大王。
- 正式卡圖路徑為 `public/cards/monsters/{id}.webp`。
- 正式戰鬥圖路徑為 `public/monsters-battle/{id}.webp`。
- 卡圖規格為 1086×1448 WebP；戰鬥圖規格為 512×512 透明 WebP。
- 山林族現有命名大量形成跨階成長線：
  - 石角幼衛 → 石角斥候 → 石角戰衛 → 石角將軍 → 石角山君 → 石角聖衛
  - 森風學徒／巡林獵手等獵人線
  - 雲嶺龍王・初醒 → 天穹
- 核准的全族規則要求各 `family × tier × slot` 都是獨立怪物，不需要角色延續或進化感。
- 女性角色以漂亮、成熟、臉部清楚為優先。

## Requirements

- 保留全部 stable IDs、數值、技能 ID、技能機制與掉落機制。
- 重新設計 36 個彼此獨立的怪物身分，不沿用跨階角色成長。
- 每階維持：
  - normalA：男性或中性人形
  - normalExisting：漂亮成年女性或適合該階的獨立身分
  - normalB：純怪物
  - miniA、miniB、boss：依階段輪替人形性別與純怪物，避免固定系列。
- 卡圖遵守 `docs/monster-art-progression.md`：
  - Tier 控制材料、能力複雜度與世界規模。
  - Encounter 控制占幅、姿態、量體與環境反應。
- 戰鬥圖使用清楚的 3.5～4 頭身半 Q 比例。
- 女性角色必須漂亮、成年、可見臉部，不以面具、腐敗或醜化表達威脅。
- 山林族只共享世界語言，不共享角色：
  - 台灣山林、溪谷、雲海、古木、岩層、風雨。
  - 主色以松綠、岩灰、霧藍、土褐為主，依 Tier 才逐步加入稀有玉石、雲金與天候法則。
- 生成順序採整族校準：
  1. 先建立 T1、T3、T6 的卡圖接觸表，確認六階跨度。
  2. 再補齊 T2、T4、T5。
  3. 卡圖核准後才以各卡圖為 reference 生成半 Q 戰鬥圖。
- 每個怪物同步重命名：
  - 怪物顯示名稱
  - 招牌技能顯示名稱與 summary 前綴
  - 掉落素材名稱
- 正式整合前全部留在 `.staging/image-generation/`。

## Acceptance Criteria

- [ ] 36 張 3:4 卡圖完成，且每階都有 3 普通、2 小王、1 大王的清楚階級差。
- [ ] T1～T6 在材料、能力與環境規模上具可辨識的逐階提升。
- [ ] 不存在同一角色跨階換裝、長大或進化的連續感。
- [ ] 36 張半 Q 戰鬥圖完成並具透明背景。
- [ ] 人形戰鬥圖落在 3.5～4 頭身；純怪物放大頭部或招牌輪廓。
- [ ] 所有女性角色符合漂亮成年女性的品質門檻。
- [ ] 每階卡圖與戰鬥圖各有一張六格聯絡表。
- [ ] 建立 T1～T6 卡圖總覽、戰鬥圖總覽與 manifest。
- [ ] staging validator、資產數量與 alpha 驗證通過。
- [ ] 使用者核准後，72 個正式 WebP 全部依 stable ID 替換。
- [ ] 36 組怪物名、技能名與素材名同步更新，技能機制保持不變。
- [ ] 全測試與 production build 通過。

## Out of Scope

- 不修改戰鬥平衡、技能倍率、怪物數值或掉落機率。
- 不同時重製其他四族。
- 未經卡圖總覽核准，不寫入 `public/` 或部署。

## Product Decisions

- 2026-07-27：六隻 `normalExisting` 的民俗舊名全部更換，與其餘 30 隻怪物採相同的獨立身分規則。
- 山豬精、百步蛇王、山魈、霧社巨人、食人巨熊、深山惡蛟不作為新立繪的名稱或造型限制。
- 只保留 stable ID、戰鬥數值、技能 ID、技能機制與掉落機制；顯示名稱、招牌技能名稱與素材名稱全部配合新身分重寫。
