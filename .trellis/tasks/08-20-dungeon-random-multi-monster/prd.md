# 地下城怪物格隨機單怪或複數怪遭遇

## Goal

讓地下城玩家踩到怪物格時，依權威隨機結果進入既有的一對一怪物戰或新的複數怪物戰，提升每次探索的遭遇變化，同時維持單人／組隊地下城的同步、續戰、獎勵與樓層完成契約。

## Requirements

- 怪物格保留一對一遭遇，並新增複數怪遭遇分支。
- 一般怪物格以固定 50%／50% 機率選擇一對一或複數怪遭遇。
- Boss 房固定改為複數怪遭遇：一隻既有鎖定 Boss 搭配兩隻小怪；Boss 預覽、實戰與重連必須保持同一隻主 Boss 與同一組小怪。
- 精英怪格固定為複數怪遭遇：一隻精英怪搭配兩隻同族一般小怪，整組遭遇必須持久化並可在重整／重連後恢復。
- 遭遇類型與怪物組合必須由地下城房間／事件 seed 決定，重整、重連及不同隊員看到相同結果。
- 複數怪戰復用已完成的多目標戰鬥規則、完整卡片／貓咪加成、不可跳過演出與音效，不另建漂移公式。
- 複數怪遭遇中，每隻怪可各自產生素材與怪物卡掉落機會；但每個怪物格的金幣、射手經驗與收藏品只結算一次。
- 所有掉落與怪物格共用同一個穩定 encounter／claim identity，重整、重連與重試不得重複入帳。
- 單人與組隊地下城都必須有明確的戰鬥交接、權威回合、勝敗、續戰與獎勵流程。
- 既有一對一怪物格、Boss 格及其他地圖事件保持相容。
- Boss 主獎勵只由主 Boss 觸發一次；兩隻小怪只套用一般怪的素材／怪物卡掉落規則，不複製 Boss 獎勵、Boss 收藏品或通關獎勵。
- 精英級獎勵只由主精英怪觸發一次；隨行小怪不可複製精英倍率、收藏品或格子級金幣／經驗。
- 本階段先完成需求與技術規劃，經確認後再實作。

## Acceptance Criteria

- [ ] 同一怪物格事件在重整／重連後保持相同遭遇類型與怪物組合。
- [ ] 一般怪物格的遭遇分支為 50% 單怪／50% 複數怪；精英格與 Boss 格固定為複數怪。
- [ ] 一對一與複數怪分支皆能完成進戰、逐回合結算、勝敗與返回地下城。
- [ ] Boss 房固定生成並保存「1 Boss + 2 小怪」，選擇頁仍預覽正確主 Boss，重整後不換怪。
- [ ] 精英格固定生成並保存「1 精英怪 + 2 一般小怪」，重整與全隊同步後不換怪。
- [ ] 組隊成員同步看到同一場複數怪戰及相同權威 resolution。
- [ ] 複數怪完整帶入角色三圍、卡片、世界王卡、裝備專精及貓咪羈絆效果。
- [ ] 秒殺仍完整播放戰鬥事件與音效後才顯示勝利。
- [ ] 獎勵不可因三隻怪或重試／重連而重複領取。
- [ ] 複數怪每隻各自判定素材／怪物卡；金幣、經驗與收藏品每個怪物格最多一次。
- [ ] Boss 主獎勵與通關只結算一次，兩隻小怪不產生額外 Boss 級獎勵。
- [ ] 精英級獎勵每格只結算一次，隨行小怪僅有一般素材／怪物卡機會。
- [ ] 舊 active dungeon room 與一對一遭遇不被破壞。
