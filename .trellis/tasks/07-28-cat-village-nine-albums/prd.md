# 貓村九冊卡片成長系統

## Goal

將現有 200 張貓貓卡片擴充為長期收藏成長系統。玩家每次取得卡片時，同時推進單卡升星與所屬建築卡冊經驗；九冊提供微量、可理解且不取代建築升級或工作貓的產能加成。

## Confirmed Facts

- 貓村有九棟建築：礦山、農地、海港、獵場、貓貓市集、露天倉庫、煉金室、扭蛋亭、練箭場。
- 貓卡共有 200 張，既有 20 個主題分類必須保留。
- 一般 198 張目前等機率；第 100、200 張各為 0.3% 特殊卡。
- 現有 `catCards` 是 `{ [cardId]: 持有數量 }`，卡片市場會增減此數量。
- 村莊建築產能已有建築等級、工作貓倍率與離線累積，不應被卡冊加成取代。

## Requirements

### 九冊歸屬

- 每張卡片新增一個固定的村莊卡冊歸屬。
- 九冊各自對應一棟村莊建築。
- 200 張卡按主題逐張分配；兩冊各 23 張、七冊各 22 張。
- 既有 20 個主題分類繼續用於全卡圖鑑篩選。

### 卡冊經驗與等級

- 九冊各自累積、各自自動升級，最高 Lv.20。
- 一般卡每次取得時，所屬卡冊永久增加 1 EXP。
- 第 100、200 張特殊卡每次取得時增加 3 EXP。
- Lv.20 累積門檻約為 1,110 EXP，採前快後慢的平方曲線。
- 每升一級，對應建築產量增加 0.25%；Lv.20 的總加成為 5%。
- 不設特色里程碑、特殊掉落或額外規則效果。
- 卡冊滿級後仍可取得、升星、出售或交換該冊卡片，但有效等級不再提高。

### 單卡升星

- 單卡最高五星。
- 沿用打怪卡升星成本：升至下一星分別消耗 1、2、3、4 張重複卡。
- 單卡升星只消耗目前持有數量，不倒扣卡冊永久 EXP。
- 市場出售與交換只影響持有數量，不倒扣卡冊永久 EXP。

### 舊玩家補算

- 首次讀取或遷移時，依玩家當下的 `catCards` 持有數量補算九冊初始 EXP。
- 已在功能上線前出售、交換或消耗且無可靠紀錄的卡片不追溯。
- 補算必須具備版本標記且只能執行一次。
- 功能上線後，每次抽卡或其他取得路徑都永久增加對應卡冊 EXP。

### UI 重設

- 扭蛋與卡片介面提供三個清楚入口：扭蛋、村莊九冊、全卡圖鑑。
- 九冊首頁使用九張建築卡冊卡片；手機兩欄，寬螢幕可增加欄數。
- 每張卡冊卡片直接顯示建築名稱、卡冊 Lv、目前/下一級 EXP、對應產量加成與收集張數。
- 點開卡冊後只顯示該冊 22～23 張卡片，提供持有數、星級、升星進度與升星操作。
- 全卡圖鑑保留既有 20 個主題分類與已收集/總數資訊。
- 抽卡揭示與十連結算顯示卡片所屬卡冊，以及該次增加的卡冊 EXP。
- 多張卡造成同冊跨越多級時合併呈現一次升級結果，避免連續彈窗。
- 未持有卡維持可辨識但鎖定資訊的圖鑑呈現；圖片採 lazy loading 與有限 fallback。

## Acceptance Criteria

- [ ] 200 張卡都有且只有一個有效卡冊歸屬，分布精確為 23、23、22×7。
- [ ] 九冊 EXP/等級以純函數計算，Lv.20 約 1,110 EXP 且加成固定為 5%。
- [ ] 抽卡、保底替換與市場取得等所有卡片取得路徑不會漏記或重複記錄卡冊 EXP。
- [ ] 升星、出售與交換不降低卡冊 EXP。
- [ ] 舊玩家補算只執行一次，舊資料缺欄位時仍能安全載入。
- [ ] 預覽產量與實際領取使用完全相同的卡冊倍率。
- [ ] 單卡可依 1/2/3/4 重複張數升至五星，交易中的保留張數不會被錯誤消耗。
- [ ] 九冊首頁在手機為兩欄且沒有水平頁面捲動。
- [ ] 九冊詳情、全卡圖鑑與抽卡結果均能正確顯示卡冊/星級資訊。
- [ ] 既有卡片市場、扭蛋保底與村莊資源測試保持通過。
- [ ] 新增卡冊分布、曲線、遷移、取得、升星及產能公式測試。
- [ ] `npm run build` 成功。

## Out of Scope

- 卡冊配置欄位或手動裝備卡片。
- 九冊特色里程碑或獨立技能。
- 卡冊等級付費、消耗材料或手動升級。
- 追溯無資料可證明的歷史出售／消耗卡片。
