# Implementation Plan

1. 建立九冊常數、200 張卡歸屬與分布不變量測試。
2. 建立 EXP 曲線、等級、倍率、補算與抽卡結果彙總純函數測試。
3. 擴充 member 資料模型與一次性舊玩家補算入口。
4. 將十連保底移入資料層，原子記錄最終抽卡與九冊 EXP。
5. 涵蓋市場購買/交換的卡片取得 EXP；取消掛賣不重複增加。
6. 新增單卡星級資料與交易式升星 API，沿用 1/2/3/4 成本。
7. 將逐棟卡冊倍率接入待領預覽與實際領取共同公式。
8. 重構扭蛋／九冊／全圖鑑 UI，加入共用卡片 tile 與詳情升星。
9. 在抽卡揭示與十連結算顯示卡冊 EXP/升級摘要。
10. 更新 Firestore rules（若 member 欄位白名單需要）。
11. 執行 focused tests、`npm test -- --watchAll=false` 相關套件與 `npm run build`。

## Risk / Rollback Points

- 十連保底現況在 UI 替換結果但資料庫早已寫入，是本功能必須一併修正的既有一致性風險。
- `catCards` 被卡市集多處當作數字，禁止改成物件格式。
- 預覽與實領若漏接任一處會出現顯示產量領不到的回歸。
- 補算必須冪等，避免多頁籤重複灌入數千 EXP。
