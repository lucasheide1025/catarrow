# 重新設計金幣商店

## Goal

重新設計會員端金幣商店，使金幣成為有持續需求、但不會直接壓過戰鬥與採集玩法的核心通用貨幣；同時改善商品價值、輪替節奏與購買介面的理解成本。

完成商店規劃後，與冒險者公會單人／組隊探索地圖回歸修復一併實作、驗證並做一次正式環境佈署。

## Confirmed Facts

- 現有商店包含五區：每日精選、每週珍寶、基本裝備、外觀、素材回收。
- 每日固定販售鐵／黃金／藥水寶箱，另從六族 T1～T3 素材包中輪替 3 種。
- 每週只輪替 1 件商品，候選為史詩寶箱、怪物卡包、咪咪箱、地下城卷軸、扭蛋幣。
- 現價約落在 150～3,000 金幣；基本裝備僅 150～200，永久外觀為 1,000～1,500。
- 素材回收每日上限 20 個，T1／T2／T3 單價為 10／25／60。
- 購買、扣款、發貨及限購計數已使用 Firestore transaction，交易一致性基礎存在。
- 專案先前已確立金幣消耗過慢，需要補給購買、裝備分解與強化等持續消耗來源。

## Requirements

- 必須先定義商店在整體經濟中的主要角色，再調整商品、價格與輪替。
- 商店定位整合「日常整備中心」與「隨機珍寶店」，在同一入口提供穩定補給與輪替商品。
- 取消永久外觀販售區；虛擬裝備一旦選定後缺乏重複購買價值，不再把它當作主要金幣回收項目。
- 規劃可直接購買的遊玩次數商品，至少包含單人打怪次數券、組隊打怪次數券與骰子次數。
- 遊玩次數券購買後放入現有「特殊活動道具」欄，不立即增加當日次數。
- 每種遊玩次數券同時具有每日購買上限與持有上限。
- 玩家可從特殊活動道具欄主動使用；相關玩法次數歸零時也應提供直接使用入口。
- 使用遊玩次數券進行的額外場次保留完整的金幣、素材、寶箱、卡片與經驗獎勵。
- 金幣商店限量販售 T1～T6 怪物素材寶箱；價格與限購需避免取代相應階級怪物、小王及大王的主要掉落價值。
- 常駐素材箱採固定階級、隨機六族：玩家購買時選 T1～T6，開箱時才隨機決定六族之一。
- 常駐素材箱不可指定族系；指定族版本僅保留給未來特殊活動或其他稀有限定來源。
- T1～T6 常駐素材箱價格／每日限購：
  - T1：500 金幣／3 箱。
  - T2：800 金幣／3 箱。
  - T3：1,200 金幣／2 箱。
  - T4：1,800 金幣／2 箱。
  - T5：2,500 金幣／1 箱。
  - T6：3,500 金幣／1 箱。
- 每箱開出 1～3 個該階隨機六族的一般素材，不包含小王／大王專屬素材。
- T1～T6 素材箱對所有正式玩家開放，不設冒險等級、角色等級或對應階級擊殺門檻。
- 新版完整金幣商店只提供正式會員；訪客／兒童模式維持獨立體驗商店，不販售正式次數券、高價珍寶、積分商品或高階成長資源。
- 訪客帳號轉為正式會員後，才顯示完整金幣商店。
- 每週珍寶不得再只提供單一商品，需擴充商品數量與選擇。
- 每週珍寶候選新增：王之印記、符文碎片、世界王地下城卷軸與貓貓箱。
- 咪咪箱不在金幣商店販售。
- 貓貓箱售價固定為 100,000 金幣，每週限購 1 個。
- 金幣商店只需發放既有貓貓箱；玩家開箱取得積分章碎片，後續現實物品兌換由既有積分系統處理。
- 不新增實體兌換券、兌換申請或另一套後台流程，也不改動既有貓貓箱／積分機制。
- 遊玩次數券採高價版：
  - 單人討伐券：1,000 金幣，單人次數 +1，每日限購 2，持有上限 5。
  - 組隊討伐券：1,500 金幣，組隊次數 +1，每日限購 1，持有上限 3。
  - 探索骰子券：750 金幣，骰子 +3，每日限購 2，持有上限 5。
- 每週珍寶固定同時上架 5 件：王之印記、隨機符文碎片包、世界王地下城卷軸、貓貓箱、怪物卡包。
- 每週珍寶初始價格與限購：
  - 王之印記 ×1：20,000 金幣，每週限購 2 次。
  - 隨機符文碎片包（隨機攻擊／防禦／生命一系 ×5）：15,000 金幣，每週限購 2 次。
  - 世界王地下城卷軸 ×1：50,000 金幣，每週限購 1 次。
  - 貓貓箱 ×1：100,000 金幣，每週限購 1 次。
  - 怪物卡包（隨機卡片 ×3）：30,000 金幣，每週限購 1 次。
- 舊鐵寶箱、黃金寶箱、史詩素材箱與舊族系素材包從金幣商店下架，但不刪除其在戰鬥／活動中的掉落來源。
- 藥水箱保留於每日商品：2,000 金幣，每日限購 2 箱。
- 今日商品固定顯示單人討伐券、組隊討伐券、探索骰子券與藥水箱。
- T1～T6 素材箱獨立成「素材補給」分頁，不參與每日隨機輪替。
- 不應讓金幣商店取代戰鬥、採集、地下城或貓貓村的主要掉落價值。
- 商品價格需能對應玩家實際金幣產出速度與預期購買週期。
- 商店主要消耗品的價格帶需高於現行版本，讓商店確實承擔金幣回收功能；遊玩次數券、日常珍品、素材箱與每週珍寶需重新定價，另保留已確認的價格例外。
- 冒險者公會的食物與飲水維持在公會商店內便宜販售，現有價格不調整，也不整合進主金幣商店。
- 食物／飲水不承擔本次主金幣回收目標；主要消耗由次數券、素材箱、每週珍寶、裝備成長及其他消耗品提供。
- 基本裝備是另一項價格例外：維持現行 150～200 金幣，讓新手能快速補齊裝備槽並開始刷素材，不承擔持續金幣回收。
- 取消永久外觀分頁與付費品牌切換；基本裝備區只顯示尚未取得的槽位，取得後自動隱藏。
- 上述基本裝備專指主線打怪模式的虛擬裝備（`rpgEquip`／`equipItems`）。
- 冒險者公會裝備是獨立系統，使用公會六維、CAT幣、碎片與公會倉庫；不與主金幣商店的虛擬裝備共用商品、槽位或操作入口。
- 本次金幣商店改版不搬移、不合併冒險者公會裝備的強化與分解功能。
- 主線 T1～T3 怪物素材回收功能保留。
- 主線怪物素材提供批量兌換升級按鈕，沿用既有低階素材合成高一階素材的規則，減少逐次操作。
- 批量素材升級提供「升級 1 次（消耗 5）」、「升級 5 次（消耗 25）」與「全部升級」。
- 「全部升級」預設保留 5 個原素材，執行前顯示總消耗、總產出與保留數量確認。
- 保留伺服器端白名單與交易式購買，避免由前端任意決定價格或獎勵。
- 商品目錄固定，不提供手動刷新、付費刷新或依日期輪替。
- 每日重置今日商品與素材箱的個人購買次數；每週一重置五項珍寶的個人購買次數。
- 新版 UI 固定五分頁：
  - 今日補給：三種次數券與藥水箱。
  - 素材補給：T1～T6 素材箱。
  - 每週珍寶：五項固定珍寶與每週限購重置倒數。
  - 新手裝備：只顯示尚未取得的主線打怪虛擬裝備槽。
  - 素材工坊：批量升級與素材回收，兩種操作分色並分開確認。
- 商店頁首顯示目前金幣、今日已花費、本週已花費、特殊活動道具入口與刷新倒數。

## Acceptance Criteria

- [ ] 商店角色、目標玩家行為與金幣消耗節奏有明確定義。
- [ ] 每一類商品都有購買理由、價格帶、限購週期與不可取代的取得來源說明。
- [ ] 金幣主要來源與主要消耗可進行收支對照，避免長期無限通膨或新手完全買不起。
- [ ] UI 能清楚說明輪替時間、持有量、限購、商品去向與購買後效果。
- [ ] 訪客、兒童及正式會員的可購買範圍有明確決策。

## Companion Fix Scope

- 單人探索需保留棋盤地圖：逐格移動、事件閱讀、遭遇戰後返回地圖、抵達最終目標才結算。
- 組隊探索目前直接進入 `teamBattle`，需補上全隊共享的地圖／旅程狀態，由房主推進且全員同步觀看事件。
- 連續進攻維持直接連戰；防守戰維持時間推進，不應共用探索地圖流程。
- 商店改版與地圖修復完成後合併驗證，再做一次 production 佈署。
