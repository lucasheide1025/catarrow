# 金幣商店改版與探索地圖修復設計

## 1. 範圍邊界

### 主金幣商店

- 處理正式會員的主線金幣、主線打怪虛擬裝備、主線怪物素材、遊玩次數券與每週珍寶。
- 不合併冒險者公會裝備、CAT幣、碎片、食物或飲水。
- 訪客／兒童繼續使用 `GuestShop`，不讀取完整商品目錄。

### 冒險者公會

- 本次只修復單人／組隊探索地圖流程。
- 連續進攻與防守戰保持獨立狀態機。

## 2. 商店目錄

以 `shopData.js` 作為唯一商品白名單與價格來源。商品增加：

- `period`: `daily`、`weekly`、`starter`。
- `inventoryKey`、`holdLimit`：特殊券持有上限。
- `grant`: 伺服器交易內可判定的發貨描述。

固定商品：

- 每日：三種遊玩券、藥水箱。
- 每日素材：T1～T6 隨機六族一般素材箱。
- 每週：王之印記、隨機符文碎片包、世界王地下城卷軸、貓貓箱、怪物卡包。
- 新手：現有主線虛擬基本裝備。

`getShopPeriodKey` 只負責取得限購重置鍵，不再決定商品是否出現。

## 3. 特殊活動道具

會員文件新增：

```js
specialItems: {
  soloBattleTicket: number,
  partyBattleTicket: number,
  boardDiceTicket: number,
}
```

購買交易同時驗證金幣、當期限購與持有上限。使用券也使用 transaction：

- 單人／組隊券：從庫存扣 1，寫入當日 `monsterSessions` 的對應 bonus 欄。
- 骰子券：從庫存扣 1，`villageBoard.dice += 3`。

每日剩餘次數計算改為「基礎上限 + 已使用券的 bonus - 已使用次數」。券使用後當日有效；未使用券可跨日保存。

## 4. 素材箱

購買時先隨機六族，再以既有 `makeFamilyMaterialChest(family, tier)` 生成寶箱，存入 `chestInventory`。

- 只使用六大族，不含寶箱族。
- 開箱沿用既有 `family_mat` 流程，產出 1～3 個同族同階一般素材。
- 不納入 `miniBoss`／`boss` 種類。

## 5. 每週珍寶發貨

- 王之印記：`members.kingSeals`。
- 符文包：交易內隨機 atk／def／hp，寫入 `equipmentRuneFragments.<type>`。
- 世界王地下城卷軸：沿用現有世界王地下城卷軸欄位／發放函式，禁止另造不相容欄位。
- 貓貓箱：發放既有 `cat_box` 寶箱。
- 怪物卡包：發放既有 `card_pack` 寶箱。

## 6. 素材工坊

將現有逐次素材升級擴充成原子批次操作：

- 1 次、5 次、全部（保留 5 個原素材）。
- 一次 transaction 計算並扣除總量、增加升級後素材。
- 回收維持每日 20 個與現有 T1／T2／T3 單價，和升級按鈕分區。

## 7. UI

`CoinShop` 重組為今日補給、素材補給、每週珍寶、新手裝備、素材工坊五頁。

- 商品卡顯示持有量、持有上限、當期限購、去向與實際效果。
- 高價商品購買前二次確認。
- 頁首顯示金幣、日／週花費、重置倒數及特殊道具入口。
- 特殊分頁顯示三種券；玩法次數耗盡時提供直接使用。

## 8. 探索地圖

### 單人

- 保留 `journey`，修正事件節點必须等待確認，戰鬥結束回到相同旅程的下一格。
- 地圖以固定格線／棋盤呈現角色位置、已探索區、視距外節點及最終目標。

### 組隊

房間文件新增共享 `journey` 與 `stage`：

```js
stage: "map" | "battle",
journey: { nodes, nodeIndex, phase, waveIndex, ... }
```

- 探索委託出發後 `stage="map"`；連續進攻／防守仍直接進戰鬥。
- 只有房主可推進或選擇避戰；所有成員訂閱相同房間快照。
- 事件閱讀閘門確認前不得推進時間、補給或戰鬥。
- 遭遇戰完成後交易式寫回下一段地圖狀態。

## 9. 相容與回滾

- 舊 `coinShopPurchases` 期間資料保留；新商品使用新 ID，不覆寫舊計數。
- 缺少 `specialItems`、`stage` 或 `journey` 的舊資料以零庫存／既有模式回退。
- 未完成的舊組隊房維持原戰鬥流程，不在中途轉換成地圖。
- 回滾可恢復舊 `CoinShop` UI；新增欄位為向後相容，不需刪除資料。
