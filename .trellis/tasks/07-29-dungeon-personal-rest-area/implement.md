# 實作計畫

1. 建立休息區純規則測試：
   - 休息只會擲出 15～50%。
   - 整備／打磨只會擲出 1～15%。
   - 新值較低保留舊最高值，新值較高才更新。
   - 祝福的顯示、金幣、角色與 50% HP 條件。
2. 建立共用休息區規則模組。
3. 新增組隊個人休息選擇 transaction，防止重複領取與重擲。
4. 使用圖片生成流程製作休息、整備、打磨、祝福四張同系列地下城插畫並保存至專案。
5. 重做 `DungeonRest` 的玩家狀態卡、響應式個人選擇卡與個人結果畫面，移除多數決。
6. 串接單人 `playerState.restBonuses`，隱藏祝福。
7. 串接組隊成員 `restBonuses`、跨房間同步與戰鬥能力計算。
8. 確認換樓時保留休息加成，事件／藥水既有重置規則不受影響。
9. 驗證房主正常等待全員，以及最上方強制通過救援按鈕。
10. 執行地下城專項測試、全專案測試與 production build。
11. 更新地下城規格，搜尋舊多數決與診斷輸出。
12. 建立四種商人抽取、商品生成與購買限制純函式測試。
13. 重建組隊商店 transaction：個人扣款、單品次數、群組互斥與數量上限。
14. 重做商人區 UI，生成四種商人及主要商品系列圖片。
15. 串接 ATK／DEF 臨時裝備、立即回血、可用攜帶型藥水庫存與族系材料寶箱；未完整生效藥水與 Level 3 只顯示鎖定卡。
16. 測試四種商人價格、T 階邊界、指定族系、購買上限、互斥限制及重新載入一致性。
17. 建立收藏品回歸測試：普通 15%、精英 45%、寶箱 55%、王 65% 與超稀有規則。
18. 將新單人／組隊遠征怪物、寶箱與王房接回共用收藏品掉落及一次性個人入帳。
19. 將寶藏房非圖鑑硬編碼珍藏品替換為當前族系正式收藏品。
20. 驗證所有掉落 ID、個人結算顯示、重載防重複，以及單人／組隊資料隔離。
