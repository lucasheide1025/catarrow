# 藥水與戰鬥狀態系統後續規格草案

此文件保留本次已確認方向，但不屬於目前地下城房間施工範圍。

## 已確認

- 保留攜帶型、投擲型、討伐型三類。
- 數值型三級基準為 10%／20%／30%，只維持該場戰鬥。
- 同系列不累加；高階可覆蓋低階，相同或低階按鈕變暗且不消耗。
- 護盾不累加，傷害先扣護盾再扣 HP；未來需有護盾條、吸收數字與破盾動畫。
- 再生藥持續三個大回合：
  - Level 1：每回合 4%
  - Level 2：每回合 7%
  - Level 3：每回合 10%
- 淨化藥暫定方向：
  - Level 1：清除一個負面狀態
  - Level 2：清除全部負面狀態
  - Level 3：清除全部並免疫下一個大回合的新負面狀態

## 必須一起設計後才能施工

- 毒
- 灼傷
- 冰凍
- 破甲
- 護盾與破盾
- 淨化
- 狀態抗性
- 狀態圖示、剩餘回合、動畫與戰鬥紀錄
- 單人、組隊、地下城、世界王共用的權威結算規則
