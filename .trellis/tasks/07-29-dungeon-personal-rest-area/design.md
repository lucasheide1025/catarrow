# 技術設計

## 核心邊界

休息區規則抽成純函式模組，UI 只負責呈現、送出選擇與播放結果：

- `rollDungeonRestValue(option, random)`：休息擲 15～50，整備／打磨擲 1～15。
- `resolveDungeonRestChoice(member, option, context)`：產生 HP、角色、最高加成與結果文案。
- `getDungeonRestOptionState(member, option, context)`：判斷祝福是否顯示、是否可用及原因。

單人與組隊都呼叫同一套規則，避免數值分歧。

## 視覺與圖片資產

- 為休息、整備、打磨、祝福生成四張同系列地下城插畫，圖片本身不放文字，文案由 HTML 呈現以確保中文清晰與無障礙。
- 圖片需保存進專案的地下城 UI 資產目錄，不引用暫存路徑。
- 選項卡採響應式設計：手機單欄大圖卡，較寬畫面使用二欄；不把四張卡硬塞成手機四欄。
- 玩家狀態卡與選項結果仍以程式 UI 呈現，確保 HP、金幣、百分比與鎖定原因即時正確。

## 商人區模型

- 進入商人房時由房主生成並保存 `shopType`：`healer`、`magic_weapon`、`magic_armor`、`mystery`。
- 商品清單由 `shopType`、地下城族系與 T 階決定，不在各玩家裝置重抽。
- 購買限制分為：
  - 本趟單品一次：三種立即回血藥（10%／200、25%／500、50%／1,000 金幣）。
  - 當次商人房單品一次：可用的 Level 1／2 攜帶型藥水（250／600 金幣）。
  - 群組互斥：三件魔法武器、三件魔法防具。
  - 單品數量上限：神秘商人各階材料寶箱 3 個。
- 組隊購買使用 transaction 同時驗證個人金幣、次數／互斥限制並寫入效果或物品，避免快速連點超買。
- 魔法武器與防具的本趟效果使用獨立欄位，不與休息區最高加成混為同一來源。
- 魔法武器與防具的 +10%／+25%／+50% 售價皆為 500／1,200／2,500 金幣。
- 神秘商人的 T 階使用目前阶级 ±1、限制 T1～T6 後去除重複。
- 神秘商人 T1～T6 指定族系素材箱售價為 600／1,000／1,500／2,200／3,000／4,200 金幣。
- 護盾、再生、淨化與其他尚未完整生效的攜帶型藥水使用不可購買的「功能準備中」卡片。
- 生命藥水商人的 Level 3 攜帶型藥水使用不可購買的預留卡，不建立假的物品 ID，也不寫入庫存。

## 狀態模型

玩家新增本趟地下城專用欄位：

```js
restBonuses: {
  atkPct: 0,
  defPct: 0,
}
```

- 打磨實際戰鬥倍率為 `1 + restBonuses.atkPct / 100`。
- 整備實際戰鬥倍率為 `1 + restBonuses.defPct / 100`。
- 每次重擲後寫入 `max(舊值, 新值)`，不與既有事件／藥水倍率相乘後回寫。
- `restBonuses` 跨樓層保留，只在本趟地下城建立時初始化，結束後隨房間／本機狀態消失。

## 組隊資料流

1. 每位玩家點選自己的選項。
2. 透過 Firestore transaction 重新讀取房間與玩家狀態。
3. transaction 驗證：
   - 玩家仍是有效成員。
   - 本休息房尚未完成選擇。
   - 祝福時角色仍為後衛且個人會員金幣至少 1,000。
4. 伺服端共享資料寫入個人效果、`roomChoices`、`roomConfirms` 與個人結果。
5. 祝福扣除會員文件 1,000 金幣，並同步角色為前衛、`displayGroup` 為前衛、HP 為 50%。
6. 全員完成後，房主可正常前進；最上方仍保留房主強制通過。

骰值必須在一次結算流程中固定並保存，畫面重載不可重擲。

## 單人資料流

- 顯示休息、整備、打磨三項。
- 點選後本機解析一次並保存結果，再由父層更新 `playerState`。
- `playerState.restBonuses` 跨房間與樓層保留。
- 不顯示祝福，也不處理角色復活。

## 相容性

- 既有 `buffs.atkMult`／`buffs.defMult` 保留給事件與商店，不拿來儲存最高休息加成。
- 戰鬥有效能力在建立戰鬥房時同時帶入 `restBonuses`。
- 舊進行中房間沒有 `restBonuses` 時視為 0。
- 不再使用休息區多數決與房主一次套用全隊效果。
- 現有護盾與再生只有局部接線且規則不一致；本輪不修改、不販售，完整狀態契約留在藥水系統後續任務。

## 本輪範圍邊界

- 本輪只施工地下城休息區與四種商人區。
- 藥水三級重整、再生倒數、護盾條、毒／灼傷／冰凍／破甲／淨化與狀態抗性全部延後。
- 生命藥水商人只販售目前已能安全使用的現有攜帶型藥水；Level 3 顯示鎖定預留卡。
- 不為了商人區新增假的護盾或異常狀態效果。

## 收藏品掉落修復

- 建立可注入亂數的共用收藏品獎勵解析器，輸入族系、房型、難度與倍率，輸出正式 `{ itemId, qty }`。
- 普通、精英、寶箱、王與寶藏房只從 `FAMILY_COLLECTIBLES[family]` 產生，輸出前以 `COLLECTIBLE_MAP` 驗證。
- 新單人遠征在個人房間完成／領取點解析一次、入帳一次，結果併入本趟結算摘要。
- 新組隊遠征不共用房主亂數結果；每位玩家領取時各自解析，並使用房間與玩家狀態避免重複領取。
- 寶箱房的 55% 收藏品為三選一以外的額外獎勵；既有三選一商品池與動畫保留。
- 寶藏房移除五個非圖鑑 `extraItem`，改用目前族系正式收藏品並在結算顯示。

## 回復方式

休息區 UI、純規則與 Firestore 結算分開修改；若交易結算驗證失敗，可回復新 UI 而不影響既有戰鬥與地圖流程。
