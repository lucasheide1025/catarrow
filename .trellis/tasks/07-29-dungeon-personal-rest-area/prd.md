# 地下城個人休息區重做

## Goal

把地下城休息區從「全隊投票、套用同一個結果」改為「每位玩家自行選擇並取得自己的效果」，讓單人與組隊玩家能依當下狀態決定回血、防禦、攻擊或復活。

## Requirements

- 休息區提供四張清楚、可個別操作的選項卡：
  - **休息**：為選擇者擲出最大 HP 的 15%～50% 並回復自己的 HP，不超過最大 HP。
  - **整備**：為選擇者擲出 DEF +1%～15%，效果持續到本次地下城結束。
  - **打磨**：為選擇者擲出 ATK +1%～15%，效果持續到本次地下城結束。
  - **祝福**：支付 1,000 金幣，讓選擇者從後衛恢復為前衛，並將 HP 設為最大 HP 的 50%。
- 組隊模式取消多數決；每位存活玩家各自選擇、各自結算。
- 每位玩家在同一個休息房只能成功選擇一次。
- 整備與打磨再次遇到休息區時必須重新擲 1%～15%，但只保留本趟地下城遇過的最高值，不可相加。
- 整備與打磨彼此獨立，因此同一趟地下城可同時持有最高 DEF 加成與最高 ATK 加成。
- 祝福只有目前角色為後衛的玩家可操作；其他玩家看到鎖定狀態。
- 祝福必須檢查玩家至少有 1,000 金幣；金幣不足時不可操作，也不可產生負數。
- 組隊房主仍等待所有有效玩家完成選擇後正常前進，並保留最上方的房主強制通過救援按鈕。
- 單人與組隊共用休息、整備、打磨三種效果規則與顯示文案。
- 「祝福」是組隊地下城專屬玩法；單人遠征必須完全隱藏此選項。
- 玩家再次倒下成為後衛，且之後再次遇到休息區時，可以再次支付 1,000 金幣使用祝福。
- 畫面需清楚顯示：
  - 自己目前 HP、前衛／後衛狀態與金幣。
  - 已持有的本趟最高 ATK／DEF 休息區加成。
  - 本次擲出的數值，以及保留新值或舊最高值的結果。
- 休息區 UI 必須完整重做，不沿用現有投票清單：
  - 玩家狀態改為清楚的大型個人狀態卡，直接呈現 HP、前／後衛、金幣及本趟最高 ATK／DEF 加成。
  - 休息、整備、打磨、祝福各自使用專屬圖片，不以 Emoji 或單色色塊作為主要視覺。
  - 圖片採一致的精緻地下城插畫風格，手機版仍須保持圖片與文字可讀。
  - 每張選項卡必須有可用、鎖定、按下、結果、保留舊最高值等清楚狀態。

## 商人區重做

- 每次進入商人區時，從四種商人中隨機出現一種；不再從所有商品混抽。
- **生命藥水商人**
  - 販售立即回復最大 HP 10%、25%、50% 的藥水，每一種在本趟地下城只能購買一次。
  - 售價分別為 200、500、1,000 金幣。
  - 同時販售目前已確實生效的 Level 1、Level 2 攜帶型藥水；Level 1 每瓶 250 金幣、Level 2 每瓶 600 金幣，每種藥水在一次商人房最多購買 1 瓶。
  - 護盾、再生、淨化等尚未完整實裝的藥水顯示「功能準備中」且不可購買。
  - UI 預留 Level 3 商品位置，但標示「尚未開放」且不可購買；數值等藥水系統重新討論後再補。
- **魔法武器商人**
  - 販售本趟地下城 ATK +10%、+25%、+50% 的臨時武器。
  - 售價分別為 500、1,200、2,500 金幣。
  - 三件只能選購其中一件；不得累進，也不可再購買另一階覆蓋。
- **魔法防具商人**
  - 販售本趟地下城 DEF +10%、+25%、+50% 的臨時防具。
  - 售價分別為 500、1,200、2,500 金幣。
  - 三件只能選購其中一件；不得累進，也不可再購買另一階覆蓋。
- **神秘商人**
  - 依目前地下城 T 階販售同族系的 T-1、T、T+1 材料寶箱。
  - 例如 T3 地下城販售 T2、T3、T4 同族系材料寶箱。
  - T1～T6 單箱售價依序為 600、1,000、1,500、2,200、3,000、4,200 金幣。
  - 每個階級最多購買 3 個。
  - 階級限制在 T1～T6；T1 顯示 T1、T2，T6 顯示 T5、T6，不產生 T0 或 T7。
- 商人類型與商品同步給整隊，所有玩家看見同一位商人；購買次數與互斥限制按玩家個別計算。
- 商人區同步重做 UI 與商人／商品圖片，清楚顯示個人金幣、購買上限、已購買及互斥鎖定原因。

## 地下城圖鑑收藏品掉落修復

- 新版單人與組隊遠征必須恢復地下城圖鑑收藏品掉落，不可只有素材箱與金幣箱。
- 掉落率沿用既有收藏節奏：普通怪物 15%、精英房 45%、寶箱房 55%、王房 65%；王房另保留難度對應的超稀有機率。
- 寶箱房收藏品獨立於原本三選一獎勵。
- 寶藏房必須從目前地下城族系的正式收藏品池產生獎勵，不得再發放圖鑑不存在的硬編碼道具 ID。
- 單人與組隊玩家都個別判定、個別入帳；組隊不可把房主的收藏品結果直接套給全隊。
- 收藏品必須顯示於個人房間結果或最終結算，重新載入或重複按領取不可重複入帳。
- 所有準備寫入的收藏品 ID 必須存在於 `COLLECTIBLE_MAP`；無效 ID 必須拒絕。

## Acceptance Criteria

- [ ] 組隊四人可以分別選擇四種不同效果，不會被多數決覆蓋。
- [ ] DEF 舊值 12%、新擲 7% 時仍保留 12%；新擲 15% 時更新為 15%。
- [ ] ATK 與 DEF 最高值分開保存，且只在本趟地下城有效。
- [ ] 非後衛無法使用祝福；後衛且金幣足夠時扣除 1,000、恢復為前衛並設為 50% HP。
- [ ] 金幣不足時祝福不扣款、不復活並顯示原因。
- [ ] 玩家完成後能閱讀自己的實際結果，其他玩家未完成前不會自動離房。
- [ ] 休息區的新玩家狀態與選項插畫在手機、平板、桌面皆清楚可讀，不出現圖片過小或卡片擠壓。
- [ ] 單人休息區只顯示休息、整備、打磨三項，不出現祝福。
- [ ] 組隊玩家再次成為後衛後，可在下一個休息區再次支付 1,000 使用祝福。
- [ ] 單人與組隊流程皆有回歸測試，production build 成功。
- [ ] 四種商人抽取皆可測試，所有隊員看見的商人種類一致。
- [ ] ATK／DEF 商人每位玩家只能購買其中一階，效果不疊加。
- [ ] 神秘商人在 T1、T3、T6 地下城分別顯示正確且不越界的族系寶箱。
- [ ] 神秘商人每一階寶箱最多購買 3 個。
- [ ] 新版普通怪、精英、寶箱、王房及寶藏房均按確認機率產生正式圖鑑收藏品。
- [ ] 單人與組隊收藏品均個別入帳、可見於結算，且不可因重載重複領取。
- [ ] 測試證明所有地下城收藏品獎勵 ID 都存在於 `COLLECTIBLE_MAP`。

## Notes

- 現行休息區是全隊投票後由房主結算同一效果，必須完整取代，不能沿用票數勝出邏輯。
- 現行前衛第一次倒下會轉為後衛並以 50% HP 繼續戰鬥；祝福要接回既有 `role`／`displayGroup` 模型。
- 休息回血量已確定為最大 HP 的隨機 15%～50%。
- 祝福不保留後衛當下 HP，也不補滿；復活後固定為最大 HP 的 50%。
- 祝福僅限組隊地下城；單人沒有前／後衛復活玩法。
- 現有程式的攜帶型藥水實際只有 Level 1 基礎與 Level 2 高級兩級。
- Level 3 這輪只在生命藥水商人預留鎖定位置，不新增藥水資料或效果；藥水系統另行重新討論。

## 後續待辦：藥水與戰鬥狀態系統（本輪不實作）

- 保留三大用途分類：
  - 攜帶型：強化或恢復自己。
  - 投擲型：攻擊怪物或施加異常，多數會取代一箭。
  - 討伐型：世界王專用並具有出戰次數限制。
- 藥水品質重新統一為三級效果尺度：
  - Level 1：10%
  - Level 2：20%
  - Level 3：30%
- 百分比增益只對該場戰鬥有效，戰鬥結束後清除，不帶到下一間戰鬥房。
- 現有各系列分散的攜帶型增益數值需重新對齊為 10%／20%／30%，不可繼續混用。
- 再生、淨化、控制等無法直接套用 10%／25%／50% 的功能型藥水，分類與三級規則尚待確認。
- 再生藥改為固定三個大回合，於每個大回合結束時自動回復：
  - Level 1：每回合最大 HP 4%。
  - Level 2：每回合最大 HP 7%。
  - Level 3：每回合最大 HP 10%。
  - 高階可覆蓋低階並將剩餘時間刷新為三回合；相同或低階不可使用。
  - 每次回血必須真正寫入 HP，顯示綠色回血數字、戰鬥紀錄與剩餘回合。
  - HP 已歸零時不可藉再生效果復活。
- 護盾正式成為可見戰鬥狀態：
  - 數值型護盾藥依 Level 1／2／3 提供最大 HP 的 10%／20%／30% 護盾。
  - 戰鬥畫面必須顯示護盾目前剩餘值與護盾條，不可只在背景計算。
  - 受到傷害時先扣護盾，再扣 HP，並顯示吸收數字與破盾回饋。
  - 護盾只維持該場戰鬥，結束後清除。
  - 單人打怪、組隊打怪、地下城與世界王的顯示及扣傷順序必須一致。
  - 同一場的護盾不可累加，只保留目前值與新藥水產生值中的較高者。
  - 新藥水無法提高目前護盾時必須阻止使用，且不可消耗庫存。
- ATK、DEF、傷害等同系列數值型藥水不可累加。
- 當藥水因同系列效果已存在而不能使用時，按鈕直接變暗並禁止點擊，不允許先點擊後才跳錯誤，也不可消耗庫存。
- 同系列允許使用更高等藥水覆蓋較低效果，但數值只更新為較高值、不相加。
- 相同或更低等級的同系列藥水直接變暗；例如已有 ATK +20% 時，+30% 可用，+10%／+20% 不可用。
