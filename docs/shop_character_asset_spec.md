# 貓貓村商店角色動畫素材 — 交接規格（給 GPT 生成用）

> 目的：請 AI 依此規格產出「商店系統 2.5D 八方向角色動畫」素材，交由遊戲端直接整合播放。
> 參考設計：`docs/shop_2.5d_animation_design_gpt.png`（八方向站姿 / Idle 4 幀 / Walk 6 幀 / Sprite Sheet 排列建議）。

---

## 1. 角色設定（Character Bible，所有圖必須一致）

**主角：橘色虎斑貓店員（代號 `shopcat`）**

| 項目 | 規範 |
|---|---|
| 風格 | 2.5D 俯視、chibi 圓潤可愛、溫暖柔和（soft 3D render 或平塗皆可，全系列統一） |
| 毛色 | 橘色虎斑（頭頂條紋、臉頰橘紋） |
| 白毛 | 口鼻、肚皮 |
| 耳朵 | 圓耳，**內耳粉色** |
| 眼睛 | 大而圓、有神（全系列同一畫法） |
| 尾巴 | 橘白相間，位置/粗細固定 |
| 服裝 | 淺色小圍裙（奶油/咖啡色系，店員感），全方向統一 |
| 頭身比 | 固定（約 2~2.5 頭身），**八方向不得變形** |
| 陰影 | 腳下一個小橢圓陰影，光線方向全系列統一（建議左上打光） |
| 禁止 | 角色身上不得出現地板/地磚/平台/底座；背景必須透明 |

**角色一致性鐵律：同一動作的 8 個方向，只有「朝向」不同，造型細節（毛色/花紋/眼睛/圍裙/尾巴）必須一模一樣。**

## 2. 方向系統（8 方位，2.5D 俯視）

| 代號 | 中文 | 視角說明 |
|---|---|---|
| `n` | 上 | 背對鏡頭（看到後背與尾巴） |
| `ne` | 右上 | 背對偏右（3/4 背向） |
| `e` | 右 | 正側面朝右 |
| `se` | 右下 | 正面前偏右（3/4 正面） |
| `s` | 下 | 正對鏡頭（看到臉） |
| `sw` | 左下 | 正面前偏左（3/4 正面） |
| `w` | 左 | 正側面朝左 |
| `nw` | 左上 | 背對偏左（3/4 背向） |

**Sprite Sheet 列順序固定（順時針）：`n → ne → e → se → s → sw → w → nw`**

---

## 3. 動作與幀數

| 動作 | 代號 | 幀數 | 內容 |
|---|---|---|---|
| 待機 | `idle` | 4 幀 | 呼吸起伏＋偶爾眨眼，循環播放 |
| 走路 | `walk` | 8 幀 | 步伐循環（左右腳交替、身體微晃、尾巴自然擺動）；已交付 e 方向為 8 幀，其餘方向比照 8 幀 |

每個動作 × 8 方向都要有。

---

## 4. 交付格式（重要）

### A. Sprite Sheet（建議，遊戲端最省事）
- 每格 **128×128 px**
- 每列一個方向，列順序照第 2 節（`n→ne→e→se→s→sw→w→nw`）
- `shopcat_idle.png` = 8 列 × 4 格 = **512×1024**
- `shopcat_walk.png` = 8 列 × 6 格 = **768×1024**
- 格與格之間**不留間距**（或固定 2px，並在交付時註明）
- 角色在每格**置中、上下留白 ≥ 8px**（頭頂與腳底不貼邊）
- 背景**透明（Alpha）**；若工具無法直接透明，可給純白底，遊戲端會自動去背

### B. 單幀（退而求其次，GPT 若拼不齊整張 sheet 時用）
- 每幀獨立一張 128×128 透明 PNG
- 命名：`shopcat_{action}_{direction}_{frame}.png`
  - 例：`shopcat_idle_se_01.png`、`shopcat_walk_n_06.png`
- frame 從 `01` 起，依播放順序編號

### C. 拆分方向（每方向一條橫排，介於 A/B 之間）
- `shopcat_idle_n.png`（4 幀橫排 512×128）、`shopcat_walk_se.png`（6 幀橫排 768×128）…共 16 張

> 三種格式只要一種即可，**A 最優先**。交付時請一併告知：用了哪種格式、間距多少、角色頭頂到格子上緣的像素數。

## 6. 遊戲端整合計畫（收到素材後由我執行）

1. **讀檔**：素材放 `public/assets/shop/characters/shopcat/`，讀取 sheet + 方向/幀數設定
2. **播放器**：寫一個 sprite 動畫元件（CSS `steps()` 或 `requestAnimationFrame`），輸入（方向, 動作, 幀率）→ 從 sheet 對應列逐幀播放、循環
3. **方向選擇**：玩家/顧客的移動向量 → 轉成 8 方位代號 → 選對應列
4. **行為切換**：站著不動 → `idle`（4 幀循環）；移動 → `walk`（6 幀循環）
5. **場景整合**：商店場景（ShopSimulatorV3）把現有靜態 chibi 換成動態 sprite——店員站櫃台待機、顧客進門→走動→貨架拿貨→排隊結帳，全程 8 方向動畫
6. **驗證**：單機 Preview 實測走路/待機切換、方向正確性
