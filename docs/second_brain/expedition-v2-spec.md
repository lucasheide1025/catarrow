## 1. 玩家決策（定案）

| 項目 | 定案 |
|---|---|
| 事件數量 | **≥10 種**事件池，每趟依難度抽 2~4 個 |
| 事件可否跳過 | **可解可不解**（不解＝不獎勵不懲罰，士氣不動） |
| 投資方式 | **六檔，追加 T1~T5 射手**（基本花費之上，不使用箭露） |
| 士氣條 | ✅ 保留（只加不減的紅利設計，基礎獎勵永不縮水） |
| 提前召回 | ❌ 不做 |
| 失敗懲罰 | **失敗＝沒有成功加成**，任何選擇都不會虧本（不扣資源、不扣獎勵） |

## 2. 事件系統

### 2.1 路線生成
- 出發時依任務難度生成事件路線，事件點分散在旅程進度：
  - T1：2 個（30% / 70%）
  - T2：3 個（25% / 50% / 75%）
  - T3：3 個（25% / 55% / 85%）
  - T4：4 個（20% / 45% / 65% / 85%）
  - T5：4 個（20% / 45% / 65% / 85%）
- 從事件池依 `minTier` 過濾後抽籤，同趟不重複
- 進度到達事件點 → 槽位卡發光脈動＋「途中遭遇！」提示，可隨時點開

### 2.2 事件卡結構（12 種）
每個事件 = 情境描述 ＋ 2 個選擇：
- **賭一把**（gamble）：`rate%` 成功 → 較大獎勵；失敗 → 無（絕不虧）
- **穩穩來**（guarantee）：穩定小獎勵 或 純 +士氣

事件池（id／名稱／minTier／情境）：
1. `old_chest` 🎒 古老寶箱（T1）－ 撬開（70% 大量材料）vs 回村通報（穩定小獎＋士氣）
2. `stray_cat` 🐾 受傷小貓（T1）－ 帶回照顧（65% 羈絆＋貓毛）vs 留點心（+羈絆）
3. `forest_fog` 🌲 迷路森林（T1）－ 相信直覺（60% 礦物）vs 紮營等霧散（+士氣大）
4. `storm` ⚡ 暴風雨（T2）－ 趁亂搜索（50% 箭露）vs 岩洞避難（+士氣）
5. `mushroom` 🍄 發光菇叢（T1）－ 小心採集（80% 藥水）vs 拍照（+士氣）
6. `stream` 🐟 清澈溪流（T1）－ 下水抓魚（70% 鮮魚）vs 喝水休息（+士氣）
7. `ruins` 🗿 古老遺跡（T3）－ 深入探索（60% 高階礦＋藥水）vs 描繪地圖（穩定礦）
8. `hunter_hut` 🏠 獵人小屋（T2）－ 請教狩獵（70% 動物肉）vs 道謝離開（+士氣）
9. `meteor` 🌠 流星雨（T2）－ 許願（50% 扭蛋幣）vs 靜靜欣賞（+士氣大）
10. `butterfly` 🦋 稀有蝴蝶（T2）－ 悄悄追捕（60% 高階貓毛）vs 靜靜觀察（+羈絆）
11. `cliff` 🏔️ 陡峭山崖（T3）－ 冒險攀爬（65% 高階礦）vs 繞路（+士氣）
12. `merchant` 🎪 流浪商人（T1）－ 聽冒險故事（70% 箭露）vs 微笑婉拒（+士氣）

- 材料獎勵的 tier = **自動跟隨任務難度**（`clamp(missionTier, 1, 5)`）→ 高難度事件報酬自然更高
- 特殊獎勵（箭露／扭蛋幣／羈絆）固定範圍

### 2.3 士氣（只加不減的紅利）
- 起始 100（上限 100）
- **不會因事件失敗而減少**；只有 T3+ 長時間任務會隨時間緩降（給「記得回來看看」的壓力）：
  - T3（24h）：-8（每 6h -2）｜T4（48h）：-16｜T5（72h）：-24
- 事件選擇（成功或穩穩來）可 +1~5 士氣
- 結算倍率：`1 + (士氣 / 100) × 0.2` → **最低 ×1.0（基礎獎勵永不縮水），最高 ×1.2**

## 3. 投資系統（六檔，只追加 T1~T5 射手，不使用箭露）

出發時選投資檔位（在基本射手花費之上**追加**，2026-08-13 改版：移除箭露成本）：

| 檔位 | 追加花費（射手） | 效果 |
|---|---|---|
| 🎒 標準 | — | 獎勵 ×1.0 |
| 🍱 輕裝 | 各階 ×1.5（進位） | 獎勵 ×1.12 |
| 🥾 充裕 | 各階 ×2（進位） | 獎勵 ×1.3 |
| 💎 奢華 | 各階 ×2.5（進位） | 獎勵 ×1.6 |
| 🏆 傳說 | 各階 ×3（進位） | 獎勵 ×1.75 ＋ 卡包機率 +5% |
| 👑 神話 | 各階 ×4（進位） | 獎勵 ×2.0 ＋ 保底 1 族系寶箱 |

（2026-08-13 調整：任務基礎射手成本加倍 T1:100 / T2:100+60 / T3:100+60+40…，
投資追加倍率提高至 ×1.5~×4，讓投資有真實成本感）

- 追加射手 = `ceil(基本數 × 倍率)`，在派遣時一併扣除 `village.resources.archer_t*`
- **頂端刻意遞減**：傳說只比奢華多 ~9% 獎勵卻多 25% 射手 → 懲罰不理性梭哈

## 3.5 探險戰利品（結算時擲，2026-08-13 新增）

領取時依「任務難度＋投資檔位」額外擲寶箱／卡包／商店商品（`rollExpeditionLoot`）：

| 難度 | 材料寶箱 | 族系寶箱 | 金幣寶箱 | 商店商品 | 怪物卡包 |
|---|---|---|---|---|---|
| T1 | 20% | 8% | 10% | 15% | 0.5% |

| T2 | 28% | 12% | 15% | 20% | 1% |
| T3 | 36% | 16% | 20% | 25% | 1.5% |
| T4 | 44% | 20% | 25% | 30% | 2% |
| T5 | 52% | 25% | 30% | 35% | 3% |

- 機率 × 投資倍率（cap 0.95）；卡包在傳說/神話另 +5%
- **族系寶箱純隨機**（七族 × 6 階，`makeFamilyMaterialChest`）
- **商店商品**＝同難度 tier 的武器/裝備/料理（1~2 種 × 1~2 件），入 `village.shop.stock` 可上架販售
- 寶箱進 `chestInventory`（`addChests`），與打怪寶箱同一背包

## 4. 結算公式（領取時，客戶端計算）

```
base       = calcExpeditionRewards(tier, catData)          // 既有基礎獎勵
eventBonus = Σ 已解事件的成功獎勵（按資源累加）
final[key] = round((base[key] + eventBonus[key]) × investMult × moraleMult)
```
- 士氣倍率最低 ×1.0 → 放空整趟也絕不虧本
- 事件「失敗」＝該選擇不加任何獎勵（+士氣照給，士氣是免費的鼓勵）

## 5. 資料模型

```js
expeditions[slot] = {
  catId, catName, missionTier, hours,
  startedAt, endsAt, status: "active",
  archerCost,                 // 含投資後總花費（寫入用）
  invest: 1 | 2 | 3 | 4 | 5 | 6,  // 投資檔位（六檔）
  morale: 100,                // 士氣
  route: [                    // 事件路線
    { id: "old_chest", at: 0.3, resolved: null },
    // resolved = { choice, success, moraleDelta, rewards: {...} }
  ],
}
```

DB 函式：
- `startExpedition(..., invest, route)` — 存 invest/morale/route，扣投資花費
- `resolveExpeditionEvent(memberId, slotIdx, eventIdx, resolved)` — 寫 route[i].resolved ＋ morale
- `collectExpedition` — 不變（客戶端傳最終聚合獎勵）

## 6. UI 動畫設計（場景化）

1. **出發動畫**：貓立繪飛入槽位＋任務圖縮放＋「🚀 出發！」彈出
2. **旅程路線圖**：槽位卡底部一條路線＋進度點（⭐ = 事件點）；時間走，進度點依序點亮
3. **事件卡**：全螢幕卡，情境描述＋貓立繪＋選擇按鈕（流光＋按下回饋）；結果漂浮獎勵圖示飛入
4. **士氣條**：槽位卡上的細動畫條（綠→黃→紅）
5. **投資選擇**：六檔金色卡片（2/3 欄網格），選中發光
6. **領取**：保留既有寶箱開箱＋獎勵卡交錯飛入

## 7. 平衡草案
- 每事件期望值 ≈ 該難度單次基礎獎勵 15~25%；平均士氣 90 → 約 +8%
- 投資只吃射手（無箭露成本）：充裕 ×1.5 換 +30%、奢華 ×2 換 +60%；頂端遞減懲罰梭哈（傳說 ×2.5 僅 +75%、神話 ×3 才 +100% 但有保底族系寶箱）
- 事件「穩穩來」的士氣獎勵設計成：長期忽略事件 → 士氣降到最低 → 只有 ×1.0（無虧，但錯過紅利）
